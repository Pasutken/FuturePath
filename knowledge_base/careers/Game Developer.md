# อาชีพ: Game Developer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: สร้างและพัฒนาวิดีโอเกมบนแพลตฟอร์มต่างๆ (PC, Console, Mobile)
- ชีวิตประจำวัน (Day-to-day): เขียนสคริปต์ควบคุมตัวละคร, ทำระบบฟิสิกส์ในเกม, ทำงานร่วมกับ Game Designer และ Artist

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: C#, C++, Game Engines (Unity, Unreal Engine), 3D Mathematics
- Soft Skills: ความคิดสร้างสรรค์ (Creativity), การทำงานเป็นทีม (Teamwork)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: การออกแบบเชิงโต้ตอบและการพัฒนาเกม, วิศวกรรมคอมพิวเตอร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เข้าร่วม Game Jam, สร้างเกมอินดี้เล็กๆ ปล่อยลงแพลตฟอร์มเช่น itch.io เพื่อเป็น Portfolio

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 20,000-35,000 บาท / Senior 60,000-100,000+ บาท
- แนวโน้มความต้องการในตลาด: โตเฉพาะกลุ่ม (Niche) การแข่งขันสูง แต่ตลาดระดับโลกยังเติบโต
