# อาชีพ: Performance Tester (Performance Test Engineer)

## 1. บทบาทและหน้าที่ (Overview)

- **สรุปสั้นๆ ว่าอาชีพนี้ทำหน้าที่อะไร:** Performance Tester ทำหน้าที่ทดสอบ "ประสิทธิภาพและความทนทานของระบบ" (Non-functional Testing) โดยไม่ได้เน้นว่าฟีเจอร์ทำงานถูกไหม (นั่นเป็นหน้าที่ของ QA ปกติ) แต่เน้นหาคำตอบว่า ถ้าระบบมีผู้ใช้งานพร้อมกันหลักหมื่นหรือหลักแสนคน ระบบจะยังทำงานได้เร็วอยู่ไหม (Load Testing), จะล่มหรือเปล่า (Stress Testing) และทนรับโหลดต่อเนื่องเป็นเวลานานได้หรือไม่ (Endurance Testing) เพื่อป้องกันเหตุการณ์ "เว็บล่ม" หรือ "แอปค้าง" ในช่วงที่มีผู้ใช้งานสูงสุด (Peak time)

- **ชีวิตประจำวัน (Day-to-day) ต้องเจอกับงานลักษณะไหน:** งานในแต่ละวันจะคลุกคลีอยู่กับการจำลองสถานการณ์และวิเคราะห์กราฟข้อมูล ได้แก่ การเขียนสคริปต์เพื่อสร้างผู้ใช้งานจำลอง (Virtual Users) จำนวนมหาศาล, การยิงโหลดเข้าสู่ระบบ (Executing Tests), การเฝ้าระวัง (Monitoring) ทรัพยากรของเซิร์ฟเวอร์ เช่น CPU, RAM, Network I/O ผ่านเครื่องมือ APM (Application Performance Monitoring) และที่สำคัญที่สุดคือการวิเคราะห์ผลลัพธ์เพื่อหา "คอขวด" (Bottlenecks) ว่าจุดไหนที่ทำให้ระบบช้า (เช่น คิวรี Database นานไป หรือ โค้ดส่วนไหนกินเมมโมรี่) จากนั้นจึงนำข้อมูลไปหารือกับ Developer, DevOps หรือ System Architect เพื่อหาทางปรับจูน (Tuning) ระบบให้เร็วขึ้น

## 2. ทักษะที่จำเป็น (Required Skills)

- **Hard Skills:** - เครื่องมือทดสอบประสิทธิภาพ (Performance Testing Tools): Apache JMeter, k6, Gatling, Micro Focus LoadRunner
  - เครื่องมือวิเคราะห์ประสิทธิภาพระบบ (APM Tools): Dynatrace, AppDynamics, New Relic, Datadog, Grafana
  - ความรู้ด้านสถาปัตยกรรมระบบ (System Architecture): เข้าใจการทำงานของ Cloud, Microservices, Kubernetes, Load Balancer, Database และ Network
  - ภาษาโปรแกรมมิ่งสำหรับการเขียนสคริปต์: Java, JavaScript, Python, Groovy

- **Soft Skills:** - การคิดวิเคราะห์หาสาเหตุที่แท้จริง (Root Cause Analysis / Analytical Thinking) การเห็นกราฟ CPU พุ่งแล้วสามารถสืบหาได้ว่าเกิดจากอะไร
  - ทักษะการสื่อสารขั้นสูง (Advanced Communication) เพื่ออธิบายปัญหาทางสถาปัตยกรรมที่ซับซ้อนให้ Developer หรือผู้บริหารเข้าใจได้ง่าย
  - ความสามารถในการรับมือกับความกดดัน (Working under pressure) เพราะมักจะเป็นด่านสุดท้ายที่ต้องรับรองว่าระบบพร้อมขึ้น Production ก่อนแคมเปญใหญ่ (เช่น 11.11 หรือระบบลงทะเบียนภาครัฐ)
  - ความอยากรู้อยากเห็นเชิงลึก (Inquisitiveness) ไม่หยุดแค่รู้ว่าระบบช้า แต่ต้องรู้ให้ได้ว่าช้าที่บรรทัดไหน หรือ Service ใด

## 3. เส้นทางการศึกษา (Educational Pathway)

- **สายตรง:** สาขาวิศวกรรมคอมพิวเตอร์ (Computer Engineering), วิทยาการคอมพิวเตอร์ (Computer Science) และเทคโนโลยีสารสนเทศ (IT) เนื่องจากต้องใช้ความรู้เชิงลึกด้านระบบปฏิบัติการและโครงสร้างเครือข่ายขั้นสูง

- **จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง:** อาชีพนี้ **"ยากมากที่จะข้ามสายมาจากสายที่ไม่ใช่ Tech"** (Non-tech switcher) ส่วนใหญ่มักเกิดจากการเติบโต/ต่อยอดมาจากตำแหน่ง QA Automation, Software Developer, System Admin หรือ DevOps Engineer ทักษะที่ต้องไปเรียนเพิ่ม (Top-up) คือการใช้เครื่องมือยิงโหลด (เช่น JMeter, k6) และการอ่านค่า Server Metrics สิ่งสำคัญในการสมัครงานคือประสบการณ์ในการวิเคราะห์ระบบที่ซับซ้อน (Complex Systems) และความสามารถในการแนะนำวิธีแก้ปัญหา (Tuning recommendations) ไม่ใช่แค่การรันเทสแล้วส่งรีพอร์ต

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)

- **ช่วงเงินเดือนสำหรับเด็กจบใหม่และคนมีประสบการณ์:** (อ้างอิงข้อมูลจริงจากรายงานตลาดแรงงาน Tech ในไทย เช่น Techsauce, PRTR, Adecco และ JobsDB)
  - **Junior (ประสบการณ์ 1-3 ปี):** ประมาณ 35,000 - 60,000 บาท/เดือน (ตำแหน่งนี้แทบไม่รับเด็กจบใหม่แกะกล่องที่ไม่มีพื้นฐานเลย มักต้องการคนที่มีประสบการณ์ QA หรือ Dev มาก่อนบ้าง)
  - **Mid-Level (ประสบการณ์ 3-5 ปี):** ประมาณ 60,000 - 100,000 บาท/เดือน
  - **Senior / Lead / Consultant (ประสบการณ์ 5 ปีขึ้นไป):** ประมาณ 100,000 - 150,000+ บาท/เดือน (หากมีความเชี่ยวชาญระดับแก้ไขปัญหาระบบสเกลใหญ่ระดับประเทศ หรือทำงานเป็นที่ปรึกษาเฉพาะทาง สามารถเรียกค่าตัวได้ถึง 150,000 - 200,000+ บาท/เดือน)

- **แนวโน้มความต้องการในตลาด:** "มีความต้องการสูงแต่เป็นตลาดเฉพาะกลุ่ม (High Demand, Niche Market) และขาดแคลนบุคลากรขั้นวิกฤต" ไม่ใช่ทุกบริษัทที่จะมีตำแหน่งนี้แบบ Full-time (บริษัทเล็กมักใช้ QA Automation หรือ Dev ทำแทนแบบผิวเผิน) แต่จะเป็นที่ต้องการตัวอย่างหนักใน "องค์กรขนาดใหญ่ที่มี Transaction สูง" เช่น ธนาคาร (Mobile Banking), บริษัท E-Commerce (แคมเปญ Flash Sale), ระบบจองตั๋ว, หรือแอปพลิเคชันที่มีผู้ใช้หลักล้านคน ซึ่งหากระบบล่มเพียง 1 นาทีอาจหมายถึงความเสียหายหลายล้านบาท บริษัทเหล่านี้จึงยอมจ่ายเงินเดือนสูงลิ่วเพื่อจ้าง Performance Tester เก่งๆ มาเป็นหลักประกันความเสี่ยง
