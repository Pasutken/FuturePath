# อาชีพ: Data Scientist

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ใช้โมเดลทางคณิตศาสตร์และ Machine Learning เพื่อทำนายอนาคตหรือหา Pattern เชิงลึก
- ชีวิตประจำวัน (Day-to-day): สร้างและจูนโมเดลพยากรณ์, ทำ A/B Testing, หา Insights ขั้นสูงเพื่อสร้างความได้เปรียบทางธุรกิจ

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Python/R, Machine Learning, Statistics, Advanced SQL
- Soft Skills: การคิดเชิงวิพากษ์ (Critical Thinking), Data Storytelling

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการข้อมูล (Data Science), สถิติประยุกต์, วิทยาการคอมพิวเตอร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องเสริมความรู้ด้านคณิตศาสตร์และสถิติให้แน่น ฝึกทำโจทย์บน Kaggle

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 35,000-60,000 บาท / Senior 90,000-150,000+ บาท
- แนวโน้มความต้องการในตลาด: เติบโตแบบก้าวกระโดด องค์กรทุกแห่งพยายามนำข้อมูลมาใช้ตัดสินใจ
