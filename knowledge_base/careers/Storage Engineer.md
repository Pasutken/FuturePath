# อาชีพ: Storage Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้เชี่ยวชาญด้านการจัดเก็บและสำรองข้อมูลจำนวนมหาศาลระดับ Hardware
- ชีวิตประจำวัน (Day-to-day): คอนฟิก SAN/NAS, ดูแลระบบ Backup & Recovery ระดับ Data Center

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Storage Architecture (NetApp, EMC), RAID, Fibre Channel, Backup Solutions
- Soft Skills: ความละเอียดรอบคอบ, ทักษะการวิเคราะห์ข้อมูลระบบ

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิศวกรรมคอมพิวเตอร์, IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เริ่มจาก System/Network แล้วเจาะจงเฉพาะทาง

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 30,000-50,000 บาท / Senior 70,000-110,000+ บาท
- แนวโน้มความต้องการในตลาด: เฉพาะทางสูงมาก มักอยู่ในธนาคารหรือองค์กรระดับ Enterprise
