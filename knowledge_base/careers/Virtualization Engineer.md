# อาชีพ: Virtualization Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: เชี่ยวชาญการจำลองเซิร์ฟเวอร์ (แบ่ง Server ใหญ่ 1 เครื่อง เป็นเครื่องเล็กๆ หลายเครื่อง)
- ชีวิตประจำวัน (Day-to-day): บริหารจัดการ VMware หรือ Hyper-V, ย้าย (Migrate) VM, จัดสรรทรัพยากร

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: VMware vSphere, Microsoft Hyper-V, Storage & Network พื้นฐาน
- Soft Skills: การวิเคราะห์ประสิทธิภาพของระบบ

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: มักเติบโตมาจาก System Admin ที่ดูแลระบบเซิร์ฟเวอร์มาก่อน

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 30,000-50,000 บาท / Senior 70,000-110,000+ บาท
- แนวโน้มความต้องการในตลาด: องค์กรระดับ On-Premise ยังต้องการสูง แต่เริ่มทับซ้อนกับ Cloud Engineer
