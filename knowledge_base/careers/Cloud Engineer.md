# อาชีพ: Cloud Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ติดตั้ง ดูแล และบริหารจัดการระบบ Infrastructure บนระบบคลาวด์
- ชีวิตประจำวัน (Day-to-day): สร้าง Virtual Machine, จัดการฐานข้อมูลบน Cloud, ตั้งค่า Network/Security บนคลาวด์

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: AWS, Azure, หรือ GCP, Linux, Terraform/Ansible
- Soft Skills: การเรียนรู้เทคโนโลยีใหม่ๆ อยู่เสมอ

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิศวกรรมคอมพิวเตอร์, IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: สอบใบเซอร์ระดับ Associate ของผู้ให้บริการ Cloud เป็นใบเบิกทาง

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 30,000-50,000 บาท / Senior 80,000-140,000+ บาท
- แนวโน้มความต้องการในตลาด: เติบโตสูงมาก เป็นสายงานที่องค์กรแย่งตัวกันมากที่สุด
