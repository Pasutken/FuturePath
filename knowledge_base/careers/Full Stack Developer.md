# อาชีพ: Full Stack Developer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: พัฒนาระบบได้ทั้งส่วนหน้า (Frontend) และหลังบ้าน (Backend)
- ชีวิตประจำวัน (Day-to-day): ดูแลโปรเจกต์แบบ End-to-end ตั้งแต่หน้าจอไปจนถึงฐานข้อมูล

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: JS Frameworks (React/Vue), Server Languages (Node/Python), Database
- Soft Skills: การบริหารเวลา (Time Management), ความยืดหยุ่น (Adaptability)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, วิศวกรรมซอฟต์แวร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เริ่มจากฝึก Frontend หรือ Backend อย่างใดอย่างหนึ่งให้เชี่ยวชาญก่อน แล้วค่อยขยายขอบเขต

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 30,000-50,000 บาท / Senior 80,000-150,000+ บาท
- แนวโน้มความต้องการในตลาด: เป็นที่ต้องการมากใน Tech Startup และ SME เพราะจ้างคนเดียวทำงานได้ครอบคลุม
