# อาชีพ: Machine Learning Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: นำโมเดล AI ที่สร้างไว้ มาทำให้ใช้งานได้จริงและสเกลได้บนระบบ Production
- ชีวิตประจำวัน (Day-to-day): เขียนโค้ดเพื่อจัดการการประมวลผลของโมเดล, ลด Latency, ดูแลระบบ ML Architecture

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Python, C++, TensorFlow/PyTorch, Software Engineering Practices (API, Docker)
- Soft Skills: การทำงานข้ามสาย (เชื่อมระหว่าง Data Scientist กับ Backend Dev)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, วิศวกรรมซอฟต์แวร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องมีพื้นฐาน Software Engineering ที่แข็งแรงมาก บวกกับความเข้าใจหลักการ ML

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 40,000-70,000 บาท / Senior 100,000-180,000+ บาท
- แนวโน้มความต้องการในตลาด: ขาดแคลนอย่างหนัก ค่าตัวสูงลิ่ว
