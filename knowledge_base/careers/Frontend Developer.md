# อาชีพ: Frontend Developer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: สร้างส่วนหน้าของเว็บไซต์หรือแอปฯ ที่ผู้ใช้งานมองเห็นและโต้ตอบด้วย
- ชีวิตประจำวัน (Day-to-day): แปลงดีไซน์ (UI/UX) ให้เป็นโค้ด, จัดหน้าเว็บ, เชื่อมต่อ API จากหลังบ้าน

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: HTML, CSS, JavaScript (React, Vue, Angular)
- Soft Skills: ความใส่ใจในรายละเอียด (Detail-oriented), การทำงานร่วมกับ Designer

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, วิศวกรรมซอฟต์แวร์, IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เรียนผ่าน Bootcamp/ออนไลน์ เน้นทำ Portfolio หน้าเว็บโชว์ผลงานจริง

## . โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 25,000-40,000 บาท / Senior 60,000-100,000+ บาท
- แนวโน้มความต้องการในตลาด: ต้องการสูงมาก ทุกธุรกิจต้องมีหน้าเว็บ/แอปพลิเคชัน
