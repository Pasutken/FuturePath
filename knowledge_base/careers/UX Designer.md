# อาชีพ: UX Designer

## 1. บทบาทและหน้าที่ (Overview)

- **สรุปสั้นๆ ว่าอาชีพนี้ทำหน้าที่อะไร:** UX Designer (User Experience Designer) ทำหน้าที่ออกแบบ "ประสบการณ์ของผู้ใช้งาน" โดยมุ่งเน้นการทำความเข้าใจปัญหา ความต้องการ และพฤติกรรมของผู้ใช้ เพื่อนำมาออกแบบโครงสร้างและลำดับการใช้งานของผลิตภัณฑ์ดิจิทัล (เช่น เว็บไซต์, แอปพลิเคชัน) ให้ใช้งานง่าย ราบรื่น และสามารถแก้ปัญหาให้ผู้ใช้ได้อย่างมีประสิทธิภาพ ควบคู่ไปกับการตอบโจทย์เป้าหมายทางธุรกิจ

- **ชีวิตประจำวัน (Day-to-day) ต้องเจอกับงานลักษณะไหน:** งานในแต่ละวันจะเน้นไปที่การวิเคราะห์และการวางแผนเป็นหลัก เช่น การทำวิจัยผู้ใช้งาน (User Research), การสัมภาษณ์และเก็บข้อมูล, การสร้างแผนภาพเส้นทางผู้ใช้งาน (User Journey Mapping), การออกแบบโครงร่างหน้าจอ (Wireframing), การทำแบบจำลองเพื่อให้ทดลองกดได้จริง (Prototyping), การนำไปทดสอบกับผู้ใช้งานจริง (Usability Testing) รวมถึงการประชุมและทำงานร่วมกับทีม UI Designer, Developer และ Product Manager เพื่อให้ผลิตภัณฑ์ออกมาตรงตามที่ออกแบบไว้

## 2. ทักษะที่จำเป็น (Required Skills)

- **Hard Skills:** - เครื่องมือออกแบบและสร้าง Prototype: Figma, Adobe XD, Sketch, InVision
  - ทักษะเฉพาะทาง: User Research, Usability Testing, Information Architecture (การจัดโครงสร้างข้อมูล), Wireframing
  - ความรู้เสริมที่ควรมี: การวิเคราะห์ข้อมูล (เช่น Google Analytics) และความเข้าใจพื้นฐานด้านโครงสร้างโค้ด (HTML/CSS) เพื่อให้สามารถออกแบบสิ่งที่ Developer นำไปสร้างจริงได้

- **Soft Skills:** - ความเข้าอกเข้าใจผู้อื่น (Empathy) เพื่อมองในมุมของผู้ใช้งาน
  - ทักษะการแก้ปัญหา (Problem-solving)
  - ทักษะการสื่อสารและการนำเสนอ (Communication & Presentation) เพื่ออธิบายเหตุผลเบื้องหลังการออกแบบให้ทีมเข้าใจ
  - การทำงานร่วมกับผู้อื่น (Collaboration)
  - การคิดเชิงวิพากษ์ (Critical Thinking)

## 3. เส้นทางการศึกษา (Educational Pathway)

- **สายตรง:** ปัจจุบันยังไม่มีคณะ UX โดยตรงในหลายมหาวิทยาลัย แต่สาขาที่ใกล้เคียงที่สุดคือ สาขาปฏิสัมพันธ์ระหว่างมนุษย์และคอมพิวเตอร์ (Human-Computer Interaction - HCI), เทคโนโลยีสารสนเทศ (IT), วิทยาการคอมพิวเตอร์ (Computer Science), การออกแบบนิเทศศิลป์/ดิจิทัลมีเดีย (Graphic/Digital Design), จิตวิทยา (Psychology) และการออกแบบอุตสาหกรรม (Industrial Design)

- **จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง:** อาชีพนี้เปิดกว้างสำหรับผู้ที่จบไม่ตรงสาย ทักษะที่ต้องไปเรียนเพิ่ม (Top-up) คือการใช้เครื่องมืออย่าง Figma และกระบวนการคิดแบบ Design Thinking สิ่งสำคัญที่สุดในการสมัครงานคือการทำ **Portfolio** ที่แสดง "กระบวนการคิด" (Case Study) โดยอาจเริ่มจากการทำโปรเจกต์สมมติ (เช่น การ Redesign แอปพลิเคชันที่มีปัญหาการใช้งาน) หรือลงเรียนคอร์สระยะสั้น (Bootcamp) เพื่อสร้างผลงานจริงและทำความเข้าใจกระบวนการทำงานในรูปแบบ End-to-end

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)

- **ช่วงเงินเดือนสำหรับเด็กจบใหม่และคนมีประสบการณ์:** (อ้างอิงข้อมูลจริงจากรายงานตลาดแรงงาน Tech ในไทย เช่น Adecco Salary Guide 2024, JobsDB)
  - **Junior (ประสบการณ์ 0-2 ปี / เด็กจบใหม่):** ประมาณ 25,000 - 45,000 บาท/เดือน (บางองค์กรเริ่มต้นที่ 30,000 บาท ขึ้นอยู่กับขนาดองค์กร)
  - **Mid-Level (ประสบการณ์ 3-5 ปี):** ประมาณ 45,000 - 70,000 บาท/เดือน
  - **Senior / Lead (ประสบการณ์ 5 ปีขึ้นไป):** ประมาณ 70,000 - 120,000+ บาท/เดือน (หากทำงานในบริษัทข้ามชาติ หรือองค์กร Tech ขนาดใหญ่ ฐานเงินเดือนสามารถสูงถึง 150,000 บาท/เดือนขึ้นไป)

- **แนวโน้มความต้องการในตลาด:** มีความต้องการสูงมากและเติบโตต่อเนื่อง ข้อมูลจากแพลตฟอร์มหางานระบุว่าตำแหน่งกลุ่มสาย Tech & Digital (ซึ่งรวมถึง UX/UI) เป็นกลุ่มที่องค์กรแย่งชิงตัวกันมากที่สุด เนื่องจากการเปลี่ยนผ่านสู่ดิจิทัล (Digital Transformation) ของภาคธุรกิจ ที่ต้องใช้แพลตฟอร์มออนไลน์เป็นหลักในการหารายได้ นอกจากนี้ยังมีโอกาสในการทำงานรูปแบบ Work from Anywhere หรือรับงานจากต่างประเทศได้โดยตรง
