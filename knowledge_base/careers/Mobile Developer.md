# อาชีพ: Mobile Developer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: พัฒนาแอปพลิเคชันบนสมาร์ทโฟน (iOS / Android)
- ชีวิตประจำวัน (Day-to-day): เขียนโค้ดแอปฯ, ทดสอบบนอุปกรณ์จริง (Device Testing), อัปเดตแอปฯ ลง Store

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Swift (iOS), Kotlin (Android), หรือ Cross-platform (Flutter, React Native)
- Soft Skills: ความเข้าใจด้าน UX บนมือถือ, การติดตามเทคโนโลยีใหม่ๆ

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, วิศวกรรมซอฟต์แวร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: โหลดเครื่องมือมาลองสร้างแอปฯ และพับลิชลง Store จริงเพื่อทำ Portfolio

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 25,000-45,000 บาท / Senior 70,000-130,000+ บาท
- แนวโน้มความต้องการในตลาด: สูงมาก ตลาดโมบายล์แอปฯ ยังคงเติบโตต่อเนื่อง
