# อาชีพ: IT Manager (ผู้จัดการฝ่ายเทคโนโลยีสารสนเทศ)

## 1. บทบาทและหน้าที่ (Overview)

- **สรุปสั้นๆ ว่าอาชีพนี้ทำหน้าที่อะไร:** IT Manager คือ "ผู้นำและผู้บริหารจัดการทรัพยากรด้านไอทีทั้งหมดขององค์กร" ทำหน้าที่กำหนดทิศทาง วางกลยุทธ์ และดูแลโครงสร้างพื้นฐานทางเทคโนโลยี (Hardware, Software, Network, Security) ให้สอดคล้องกับเป้าหมายทางธุรกิจของบริษัท รวมถึงการบริหารจัดการงบประมาณและทีมงานไอที (เช่น Helpdesk, System Admin, Network Engineer) ให้ทำงานได้อย่างมีประสิทธิภาพ

- **ชีวิตประจำวัน (Day-to-day) ต้องเจอกับงานลักษณะไหน:** งานในแต่ละวันจะเน้นไปที่การบริหารจัดการ (Management) และการวางกลยุทธ์ (Strategy) มากกว่าการลงมือทำด้านเทคนิค (Hands-on) ด้วยตัวเอง เช่น การประชุมกับผู้บริหารระดับสูง (C-Level) เพื่ออัปเดตแผนงานไอที, การบริหารงบประมาณ (IT Budgeting), การเจรจาต่อรองและจัดซื้อจัดจ้างกับ Vendor ภายนอก (Vendor Management), การประเมินความเสี่ยงและวางแผนกู้คืนระบบ (Disaster Recovery Plan), การคุมโปรเจกต์ไอทีใหม่ๆ (IT Project Management) และการดูแลประเมินผลงาน (KPIs) ของคนในทีม

## 2. ทักษะที่จำเป็น (Required Skills)

- **Hard Skills:** - มาตรฐานการจัดการบริการไอทีและโปรเจกต์: ITIL, PMP (Project Management Professional), Agile/Scrum
  - ความรู้ภาพรวมเชิงโครงสร้าง (High-level Architecture): เข้าใจหลักการทำงานของ Cloud (AWS, Azure, GCP), Server/Network Infrastructure และ Cybersecurity
  - การบริหารงบประมาณและการเงิน (Budgeting & Financial Management) สำหรับแผนกไอที
  - การบริหารจัดการสัญญาและ Vendor (Contract & Vendor Management)
  - ความรู้ด้านกฎหมายที่เกี่ยวข้องกับไอที: เช่น PDPA, GDPR หรือ ISO 27001

- **Soft Skills:** - ความเป็นผู้นำและการบริหารคน (Leadership & People Management) เป็นทักษะที่สำคัญที่สุดในการดึงศักยภาพและรักษาคนเก่งในทีมไว้
  - วิสัยทัศน์และการคิดเชิงกลยุทธ์ (Strategic Thinking) เพื่อนำเทคโนโลยีมาสร้างข้อได้เปรียบทางธุรกิจ
  - การตัดสินใจอย่างเด็ดขาด (Decision Making) โดยเฉพาะในภาวะวิกฤต เช่น ระบบล่มหรือโดนแฮกเกอร์โจมตี
  - ทักษะการสื่อสารระดับผู้บริหาร (Executive Communication) สามารถนำเสนอเรื่องเทคนิคซับซ้อนให้บอร์ดบริหารอนุมัติงบประมาณได้

## 3. เส้นทางการศึกษา (Educational Pathway)

- **สายตรง:** ระดับปริญญาตรีหรือปริญญาโท สาขาเทคโนโลยีสารสนเทศ (IT), วิทยาการคอมพิวเตอร์ (Computer Science), วิศวกรรมคอมพิวเตอร์ (Computer Engineering) หรือ ระบบสารสนเทศเพื่อการจัดการ (MIS) หลายคนมักจะเรียนต่อระดับปริญญาโทด้านบริหารธุรกิจ (MBA) เพื่อเสริมทักษะด้าน Management

- **จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง:** **"เป็นตำแหน่งที่ไม่สามารถเป็นได้ทันทีหลังเรียนจบ"** IT Manager คือระดับบริหาร (Management Level) ผู้ที่จะก้าวขึ้นมาตำแหน่งนี้มักต้องผ่านประสบการณ์การทำงานสาย Tech อย่างน้อย 7-10 ปี มักเติบโตมาจาก System Administrator, Network Engineer, IT Support Lead หรือ Software Project Manager สิ่งที่เสริมโปรไฟล์ให้โดดเด่นในการโปรโมตหรือสมัครงานคือ **ใบประกาศนียบัตร (Certification)** ระดับบริหาร เช่น **ITIL Managing Professional**, **PMP**, **CISM** (Certified Information Security Manager) หรือ **CISSP**

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)

- **ช่วงเงินเดือนสำหรับเด็กจบใหม่และคนมีประสบการณ์:** (อ้างอิงข้อมูลจริงจากรายงานตลาดแรงงาน Tech ในไทย เช่น Adecco Salary Guide, PRTR, Techsauce และ JobsDB)
  - **Junior:** **ไม่มีตำแหน่งนี้สำหรับเด็กจบใหม่**
  - **New/Junior IT Manager (ประสบการณ์ทำงานรวม 7-10 ปี / ประสบการณ์บริหาร 1-3 ปี):** ประมาณ 70,000 - 100,000 บาท/เดือน
  - **Mid-Level IT Manager (ประสบการณ์บริหาร 3-5 ปี):** ประมาณ 100,000 - 150,000 บาท/เดือน
  - **Senior IT Manager / IT Director (ประสบการณ์บริหาร 7-10 ปีขึ้นไป):** ประมาณ 150,000 - 250,000+ บาท/เดือน (ในองค์กรระดับ Enterprise หรือบริษัทข้ามชาติ เงินเดือนและผลประโยชน์รวมสามารถสูงถึง 250,000 - 350,000 บาท/เดือน)

- **แนวโน้มความต้องการในตลาด:** "มีความต้องการสูงและมั่นคงมาก" ทุกองค์กรขนาดกลางถึงขนาดใหญ่ (Medium to Large Enterprise) ล้วนต้องมี IT Manager เป็นแกนหลักในการขับเคลื่อนระบบหลังบ้านและทำ Digital Transformation อย่างไรก็ตาม การแข่งขันในตำแหน่งนี้ก็สูงเช่นกัน องค์กรในปัจจุบันไม่ได้มองหา IT Manager ที่เก่งแค่เรื่องซ่อมคอมพิวเตอร์หรือคุมเซิร์ฟเวอร์อีกต่อไป แต่ต้องการ **"Business Partner"** ที่เข้าใจธุรกิจ และสามารถนำเทคโนโลยีมาช่วยลดต้นทุนหรือเพิ่มรายได้ให้กับบริษัทได้จริง อาชีพนี้ยังเป็นบันไดก้าวสำคัญเพื่อต่อยอดไปสู่ตำแหน่งระดับผู้บริหารสูงสุด (C-Level) อย่าง CIO (Chief Information Officer) หรือ CTO (Chief Technology Officer) ในอนาคต
