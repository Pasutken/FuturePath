# อาชีพ: Cybersecurity Analyst

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: เป็นด่านหน้าคอยวิเคราะห์ความเสี่ยงและตรวจสอบช่องโหว่ของระบบคอมพิวเตอร์
- ชีวิตประจำวัน (Day-to-day): วิเคราะห์ Logs แจ้งเตือนความปลอดภัย, ประเมินความเสี่ยง, ให้ความรู้พนักงาน

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: SIEM Tools, Security Frameworks, Vulnerability Scanning, Network Protocols
- Soft Skills: ความช่างสังเกต, ความกระตือรือร้นในการติดตามข่าวสารภัยคุกคาม

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: ความมั่นคงปลอดภัยไซเบอร์ (Cybersecurity), IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: สอบใบเซอร์ CompTIA Security+ เพื่อพิสูจน์ความรู้พื้นฐาน

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 30,000-45,000 บาท / Senior 70,000-120,000+ บาท
- แนวโน้มความต้องการในตลาด: โตวันโตคืน ยิ่งอาชญากรรมไซเบอร์เก่งขึ้น อาชีพนี้ยิ่งสำคัญ
