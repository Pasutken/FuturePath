# อาชีพ: Penetration Tester (Ethical Hacker)

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: แฮกเกอร์หมวกขาว ถูกจ้างมาเพื่อเจาะระบบขององค์กรเพื่อหาช่องโหว่ก่อนที่แฮกเกอร์ตัวจริงจะมาเจอ
- ชีวิตประจำวัน (Day-to-day): โจมตีเว็บแอปพลิเคชัน โจมตีเซิร์ฟเวอร์, เขียนรายงานสรุปช่องโหว่

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Web/Network Exploitation, Kali Linux, Metasploit, Burp Suite, Programming
- Soft Skills: คิดแบบโจร (Attacker Mindset), จริยธรรมขั้นสูง (Ethics), ทักษะการเขียนรายงานเชิงเทคนิค

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: Cybersecurity, วิทยาการคอมพิวเตอร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ฝึกวิชาบนแพลตฟอร์มอย่าง HackTheBox และล่าใบเซอร์ตัวท็อปอย่าง OSCP

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 40,000-60,000 บาท / Senior 90,000-150,000+ บาท
- แนวโน้มความต้องการในตลาด: รายได้ดีมากและท้าทาย บริษัทรับทำ Pentest ภายนอกมักต้องการตัวสูง
