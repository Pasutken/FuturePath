# อาชีพ: Cloud Architect

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ออกแบบภาพรวมของระบบคลาวด์ขององค์กร เพื่อให้ประหยัดงบ ปลอดภัย และมีประสิทธิภาพสูงสุด
- ชีวิตประจำวัน (Day-to-day): วางแผนกลยุทธ์การนำระบบขึ้นคลาวด์, ออกแบบสถาปัตยกรรม High Availability

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: เชี่ยวชาญ Cloud Services ระดับสูง, Cost Optimization, Security Architecture
- Soft Skills: ภาวะผู้นำ, ทักษะการพรีเซนต์ระดับผู้บริหาร

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: ไต่เต้ามาจาก Cloud Engineer หรือ System Admin ที่มีประสบการณ์สูง
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องอาศัยประสบการณ์ตรงหลายปีในการวางระบบขนาดใหญ่ + สอบใบเซอร์ระดับ Professional

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Senior/Lead Level 120,000-250,000+ บาท
- แนวโน้มความต้องการในตลาด: ขาดแคลนอย่างหนัก ค่าตอบแทนสูงมาก
