# อาชีพ: Data Architect

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ออกแบบพิมพ์เขียวของระบบข้อมูล (Data Blueprint) ทั้งหมดในองค์กร
- ชีวิตประจำวัน (Day-to-day): กำหนดมาตรฐานการจัดเก็บข้อมูล, เลือก Database หรือ Cloud Provider ที่เหมาะสมกับกลยุทธ์บริษัท

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Data Modeling, Cloud Architecture, Big Data Ecosystem, System Integration
- Soft Skills: การสื่อสารระดับบริหาร, วิสัยทัศน์ทางธุรกิจ

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: ต้องมีประสบการณ์ระดับ Senior Data Engineer หรือ Database Admin มาก่อน
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องสั่งสมประสบการณ์ในการวางระบบ Data ระดับ Enterprise หลายปี

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Senior/Lead Level 120,000-250,000+ บาท
- แนวโน้มความต้องการในตลาด: ต้องการสูงในองค์กรขนาดใหญ่ระดับ Enterprise หรือธนาคาร
