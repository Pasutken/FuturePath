# อาชีพ: UI Designer

## 1. บทบาทและหน้าที่ (Overview)

- **สรุปสั้นๆ ว่าอาชีพนี้ทำหน้าที่อะไร:** UI Designer (User Interface Designer) ทำหน้าที่ออกแบบ "ส่วนติดต่อผู้ใช้งาน" หรือหน้าตาของแอปพลิเคชันและเว็บไซต์ มุ่งเน้นไปที่ความสวยงาม (Aesthetics) และการใช้งานที่ตอบสนองได้ดี (Interactivity) โดยรับผิดชอบการออกแบบองค์ประกอบต่างๆ ที่ผู้ใช้ต้องมองเห็นและโต้ตอบด้วย เช่น ปุ่มกด, ไอคอน, การจัดวาง (Layout), การเลือกใช้สี (Color Palette) และตัวพิมพ์ (Typography) เพื่อให้ผลิตภัณฑ์ดูน่าใช้ สื่อสารเอกลักษณ์ของแบรนด์ และใช้งานได้ง่ายตามโครงสร้างที่วางไว้

- **ชีวิตประจำวัน (Day-to-day) ต้องเจอกับงานลักษณะไหน:** งานในแต่ละวันจะเน้นไปที่การลงมือออกแบบภาพกราฟิกและองค์ประกอบบนหน้าจอ (Visual Design) โดยมักจะรับโครงร่าง (Wireframe) มาจาก UX Designer เพื่อนำมาออกแบบเป็นภาพเสมือนจริง (High-Fidelity Mockup) งานประจำวันได้แก่ การสร้างและจัดการ Design System (ระบบการออกแบบมาตรฐานของแบรนด์), การออกแบบการเคลื่อนไหวขนาดเล็ก (Micro-interactions), การปรับขนาดหน้าจอให้รองรับทุกอุปกรณ์ (Responsive Design) รวมถึงการส่งมอบงานออกแบบ (Design Handoff) และสื่อสารกับฝั่ง Developer (โปรแกรมเมอร์) เพื่อให้เขียนโค้ดออกมาได้ตรงตามดีไซน์ (Pixel-perfect)

## 2. ทักษะที่จำเป็น (Required Skills)

- **Hard Skills:** - เครื่องมือออกแบบหน้าจอและเวกเตอร์: Figma, Adobe XD, Sketch, Adobe Illustrator, Adobe Photoshop
  - ทักษะเฉพาะทาง: ความรู้ด้านทฤษฎีสี (Color Theory), การจัดวางองค์ประกอบและระบบกริด (Layout & Grid System), การจัดแบบตัวอักษร (Typography), การสร้าง Design System และ Component
  - ความรู้เสริมที่ควรมี: ความเข้าใจข้อจำกัดของการเขียนโค้ด (HTML/CSS) เบื้องต้น เพื่อให้ออกแบบหน้าจอที่ Developer สามารถนำไปพัฒนาต่อได้จริง

- **Soft Skills:** - ความใส่ใจในรายละเอียดขั้นสูง (Attention to Detail / Pixel-perfect mindset)
  - ทักษะการสื่อสาร (Communication) เพื่ออธิบายเหตุผลในการเลือกใช้สีหรือการจัดวางให้ทีมเข้าใจ
  - การทำงานร่วมกับผู้อื่น (Collaboration) โดยเฉพาะกับ UX Designer และ Developer
  - ความคิดสร้างสรรค์และความเปิดรับ (Creativity & Adaptability) เพื่ออัปเดตเทรนด์การออกแบบใหม่ๆ อยู่เสมอ

## 3. เส้นทางการศึกษา (Educational Pathway)

- **สายตรง:** คณะหรือสาขาที่เกี่ยวข้องกับการออกแบบภาพกราฟิกโดยตรง เช่น สาขาการออกแบบนิเทศศิลป์ (Visual Communication Design), การออกแบบกราฟิก (Graphic Design), ดิจิทัลมีเดียอาร์ต (Digital Media Arts), ศิลปกรรมศาสตร์ หรือสถาปัตยกรรมศาสตร์ (Industrial Design) 

- **จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง:** เปิดกว้างสำหรับผู้ที่ไม่มีวุฒิการศึกษาด้านการออกแบบโดยตรง ทักษะที่ต้องไปเรียนเพิ่ม (Top-up) คือการใช้เครื่องมือมาตรฐานอุตสาหกรรมอย่าง Figma และทำความเข้าใจหลักการออกแบบ UI (UI Design Principles) รวมถึงการทำความเข้าใจ Guideline ของระบบปฏิบัติการต่างๆ (เช่น Apple Human Interface Guidelines หรือ Google Material Design) สิ่งสำคัญที่สุดคือการสร้าง **Portfolio** ที่เน้นโชว์ผลงานความสวยงาม การจัดวางที่เป็นระเบียบ และความสามารถในการทำชิ้นงานให้ดูเป็นมืออาชีพ (Visual Craftsmanship)

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)

- **ช่วงเงินเดือนสำหรับเด็กจบใหม่และคนมีประสบการณ์:** (อ้างอิงข้อมูลจริงจากรายงานตลาดแรงงานและแพลตฟอร์มประกาศงานในไทย เช่น JobsDB และ Adecco Salary Guide)
  - **Junior (ประสบการณ์ 0-2 ปี / เด็กจบใหม่):** ประมาณ 20,000 - 35,000 บาท/เดือน
  - **Mid-Level (ประสบการณ์ 3-5 ปี):** ประมาณ 35,000 - 55,000 บาท/เดือน
  - **Senior / Lead (ประสบการณ์ 5 ปีขึ้นไป):** ประมาณ 60,000 - 120,000+ บาท/เดือน (บางองค์กรที่เป็นบริษัทเทคโนโลยีขนาดใหญ่หรือบริษัทข้ามชาติ อาจเสนอเงินเดือนสูงถึง 120,000 - 150,000 บาท/เดือน หากมีทักษะการบริหารจัดการ Design System สเกลใหญ่)

- **แนวโน้มความต้องการในตลาด:** มีความต้องการในตลาดแรงงานสูงมากเช่นเดียวกับ UX Designer หลายบริษัทมักจะรวมตำแหน่งเป็น "UX/UI Designer" เพื่อความคุ้มค่า แต่สำหรับองค์กรขนาดใหญ่ (เช่น ธนาคาร, บริษัท E-commerce, Tech Company) จะมีการแยกตำแหน่ง UI Designer ออกมาอย่างชัดเจน เพื่อมุ่งเน้นความสวยงามและการรักษามาตรฐานของแบรนด์ (Brand Identity) นอกจากนี้ทักษะ UI Design ยังเป็นที่ต้องการสูงในตลาดฟรีแลนซ์ทั้งในและต่างประเทศ
