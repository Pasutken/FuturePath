# อาชีพ: Computer Vision Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: สอนคอมพิวเตอร์ให้มองเห็นและเข้าใจภาพหรือวิดีโอ
- ชีวิตประจำวัน (Day-to-day): ประมวลผลภาพ (Image Processing), สร้างโมเดล Object Detection หรือ Image Classification

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Python, C++, OpenCV, Deep Learning (CNNs)
- Soft Skills: คณิตศาสตร์ (เรขาคณิต, แคลคูลัส), การแก้ปัญหา

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิศวกรรมคอมพิวเตอร์, วิศวกรรมหุ่นยนต์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องมีพื้นคณิตศาสตร์แน่น และฝึกทำโปรเจกต์เกี่ยวกับการวิเคราะห์ภาพ

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 40,000-65,000 บาท / Senior 100,000-180,000+ บาท
- แนวโน้มความต้องการในตลาด: สูงมากในอุตสาหกรรมโรงงาน (QC), ความปลอดภัย, และยานยนต์
