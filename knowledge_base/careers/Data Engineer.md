# อาชีพ: Data Engineer 

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้วางระบบท่อส่งข้อมูล (Data Pipeline) รวบรวมข้อมูลจากหลายแหล่งมาจัดเก็บให้พร้อมใช้งาน
- ชีวิตประจำวัน (Day-to-day): เขียนสคริปต์ดึงข้อมูล (ETL), ดูแล Data Warehouse / Data Lake, ออกแบบสถาปัตยกรรมข้อมูล

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Python, SQL ระดับสูง, Spark, Airflow, Cloud Data Services
- Soft Skills: ความรอบคอบ, ทักษะการแก้ปัญหาระบบล่ม (Troubleshooting)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิศวกรรมคอมพิวเตอร์, วิทยาการคอมพิวเตอร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: มักย้ายมาจากสาย Software / Backend Dev ต้องเสริมทักษะ Data Architecture

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 35,000-60,000 บาท / Senior 100,000-180,000+ บาท
- แนวโน้มความต้องการในตลาด: ขาดแคลนมากที่สุดในสาย Data เพราะเป็นพื้นฐานก่อนจะไปทำ AI/Data Science
