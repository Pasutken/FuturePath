# อาชีพ: System Administrator

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ดูแลและบำรุงรักษาระบบคอมพิวเตอร์และเซิร์ฟเวอร์ขององค์กรให้ทำงานได้ปกติ
- ชีวิตประจำวัน (Day-to-day): ตั้งค่า User/Password, ลง OS, อัปเดตแพตช์ (Patch), แก้ปัญหาคอมพิวเตอร์และเซิร์ฟเวอร์

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Windows Server, Linux, Active Directory, Scripting (PowerShell/Bash)
- Soft Skills: การบริการ (Service Mind), การรับมือกับความเครียดเมื่อระบบขัดข้อง

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, เทคโนโลยีสารสนเทศ (IT)
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เริ่มต้นจาก IT Support สะสมประสบการณ์และสอบใบเซอร์ (เช่น CompTIA Server+)

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 20,000-35,000 บาท / Senior 50,000-80,000+ บาท
- แนวโน้มความต้องการในตลาด: ทรงตัว องค์กรเริ่มย้ายระบบขึ้น Cloud จึงควรต้องอัปสกิลไปสู่สาย Cloud Engineer
