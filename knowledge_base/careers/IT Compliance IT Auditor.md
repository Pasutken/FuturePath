# อาชีพ: IT Compliance / IT Auditor

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ตรวจสอบระบบ IT ว่าทำงานได้ตามมาตรฐาน กฎหมาย และนโยบายขององค์กรหรือไม่
- ชีวิตประจำวัน (Day-to-day): สุ่มตรวจกระบวนการทำงานของแผนก IT, ขอดูหลักฐานการตั้งค่าระบบ, เขียนรายงานข้อบกพร่อง

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: IT Frameworks (COBIT, ITIL), กฎหมายข้อบังคับ, กระบวนการ Audit
- Soft Skills: ความตรงไปตรงมา, ทักษะการสัมภาษณ์, ทักษะการเขียนเชิงธุรกิจ

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: บัญชี (และมาต่อยอด IT), ระบบสารสนเทศ
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ผู้สอบบัญชีสามารถเรียนรู้ Framework ด้าน IT เพิ่มเติมและสอบใบเซอร์ CISA

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 30,000-50,000 บาท / Senior 80,000-140,000+ บาท
- แนวโน้มความต้องการในตลาด: ตลาดต้องการมากในบริษัทมหาชนหรือธนาคารที่ต้องถูก Audit เป็นประจำตามกฎระเบียบ
