# อาชีพ: Network Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ออกแบบ ติดตั้ง และดูแลระบบเครือข่ายอินเทอร์เน็ตและอินทราเน็ตขององค์กร
- ชีวิตประจำวัน (Day-to-day): คอนฟิก Router/Switch, เดินสาย, แก้ปัญหาอินเทอร์เน็ตช้าหรือหลุด

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Routing/Switching (Cisco/Aruba), TCP/IP, OSI Model, Firewall พื้นฐาน
- Soft Skills: การแก้ปัญหาเฉพาะหน้า, ความรอบคอบ

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิศวกรรมโทรคมนาคม, เทคโนโลยีสารสนเทศ
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องสอบใบเซอร์ CCNA (Cisco Certified Network Associate) ถือเป็นภาคบังคับ

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 20,000-35,000 บาท / Senior 50,000-90,000+ บาท
- แนวโน้มความต้องการในตลาด: คงที่ แต่ต้องปรับตัวไปเรียนรู้ Cloud Networking หรือ SDN เพิ่มเติม
