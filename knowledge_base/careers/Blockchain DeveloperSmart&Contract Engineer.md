# อาชีพ: Blockchain Developer / Smart Contract Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: พัฒนาระบบกระจายศูนย์ (Decentralized) และเขียนสัญญาอัจฉริยะ (Smart Contract)
- ชีวิตประจำวัน (Day-to-day): เขียนโค้ดบน Blockchain, ทดสอบความปลอดภัยของ Smart Contract, พัฒนา dApps

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Solidity, Rust, Web3.js, Cryptography พื้นฐาน
- Soft Skills: ความระมัดระวังขั้นสุดยอด, การเรียนรู้ไว

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, วิศวกรรมซอฟต์แวร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ศึกษาการทำงานของ Blockchain และเขียน Smart Contract จำลองบน Testnet

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 40,000-70,000 บาท / Senior 100,000-200,000+ บาท
- แนวโน้มความต้องการในตลาด: ผันผวนตามตลาดคริปโตฯ แต่เทคโนโลยีนี้ยังเป็นที่ต้องการในภาคการเงิน (DeFi)
