# อาชีพ: System Analyst (SA)

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ทำความเข้าใจความต้องการของธุรกิจ และออกแบบระบบ IT ออกมาเป็นสเปกให้โปรแกรมเมอร์
- ชีวิตประจำวัน (Day-to-day): สัมภาษณ์ User เพื่อเก็บ Requirement, เขียนเอกสาร System Design, ตรวจสอบระบบก่อนส่งมอบ

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: SDLC, UML, SQL พื้นฐาน
- Soft Skills: การสื่อสารยอดเยี่ยม, การเจรจาต่อรอง, การวิเคราะห์และจับประเด็น

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: ระบบสารสนเทศเพื่อการจัดการ (MIS), เทคโนโลยีสารสนเทศ
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: หากมาจากฝั่ง Business ต้องเรียนรู้พื้นฐาน IT Development เพื่อสื่อสารกับทีม Dev ให้เข้าใจ

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 25,000-45,000 บาท / Senior 70,000-120,000+ บาท
- แนวโน้มความต้องการในตลาด: เป็นตัวกลางสำคัญที่ทุกบริษัทที่พัฒนาซอฟต์แวร์ต้องมี
