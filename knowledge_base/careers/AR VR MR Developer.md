# อาชีพ: AR/VR/MR Developer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: พัฒนาระบบโลกเสมือนจริง (VR) หรือการผสานโลกจริงกับโลกเสมือน (AR/MR)
- ชีวิตประจำวัน (Day-to-day): เขียนแอปฯ ที่ใช้ร่วมกับแว่น VR/AR, ทำงานกับโมเดล 3D, ปรับแต่งการตอบสนองของเซนเซอร์

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Unity, Unreal Engine, C#, C++, 3D Modeling concepts
- Soft Skills: จินตนาการด้านมิติสัมพันธ์, ความเข้าใจ User Experience ในโลก 3D

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, เทคโนโลยีมัลติมีเดีย
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ศึกษาผ่าน Game Engine และทดลองทำโปรเจกต์ 3D ด้วยตัวเอง

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
ช่วงเงินเดือน: Junior 25,000-45,000 บาท / Senior 70,000-120,000+ บาท
แนวโน้มความต้องการในตลาด: กำลังเติบโต โดยเฉพาะในกลุ่มการแพทย์ การศึกษา และอสังหาริมทรัพย์
