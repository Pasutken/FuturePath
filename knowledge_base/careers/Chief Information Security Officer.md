# อาชีพ: Chief Information Security Officer (CISO)

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้บริหารระดับสูง (C-Level) ที่ดูแลภาพรวมด้านความปลอดภัยข้อมูลของทั้งองค์กร
- ชีวิตประจำวัน (Day-to-day): กำหนดกลยุทธ์, บริหารงบประมาณ, นำเสนอบอร์ดบริหาร, เป็นตัวแทนองค์กรเมื่อเกิดเหตุ

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: ทักษะรอบด้านในหมวด Security ทั้งหมด, การบริหารความเสี่ยง (Risk Management)
- Soft Skills: ทักษะการบริหารคน, ภาวะผู้นำระดับสูง, ทักษะการโน้มน้าวใจ

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: เติบโตจากสาย Security/IT สะสมประสบการณ์ 10-15 ปีขึ้นไป
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เป็นจุดสูงสุด ต้องมีทั้งประสบการณ์ลึกซึ้งและใบเซอร์ระดับบริหารอย่าง CISSP

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: ผู้บริหารระดับสูง 200,000-500,000+ บาท (ขึ้นอยู่กับขนาดองค์กร)
- แนวโน้มความต้องการในตลาด: องค์กรใหญ่เริ่มตื่นตัวและเห็นความสำคัญของการมีกัปตันเรือด้านความปลอดภัยมากขึ้น
