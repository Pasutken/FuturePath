# อาชีพ: Data Governance Analyst

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้คุมกฎและมาตรฐานของข้อมูลในองค์กร ให้ข้อมูลมีความถูกต้องและปลอดภัยตามกฎหมาย
- ชีวิตประจำวัน (Day-to-day): จัดทำ Data Dictionary, วางนโยบายสิทธิ์การเข้าถึงข้อมูล, ตรวจสอบคุณภาพข้อมูล

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Data Governance Frameworks, SQL (เพื่อตรวจสอบข้อมูล), กฎหมาย PDPA
- Soft Skills: การเจรจาต่อรอง (Negotiation), การจัดการเอกสาร (Documentation)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: บริหารธุรกิจ, ระบบสารสนเทศเพื่อการจัดการ (MIS), นิติศาสตร์ประยุกต์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องศึกษาข้อกฎหมาย IT และมาตรฐานความปลอดภัยของข้อมูลเพิ่มเติม

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 30,000-45,000 บาท / Senior 70,000-120,000 บาท
- แนวโน้มความต้องการในตลาด: โตขึ้นมากหลังจากมีกฎหมายคุ้มครองข้อมูลส่วนบุคคลบังคับใช้
