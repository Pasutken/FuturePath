# อาชีพ: Database Administrator (DBA)

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ดูแล บำรุงรักษา และรับประกันว่าฐานข้อมูล (Database) จะใช้งานได้ตลอดเวลา
- ชีวิตประจำวัน (Day-to-day): Backup/Restore ข้อมูล, จูนนิ่งให้ Database ทำงานเร็วขึ้น, จัดการพื้นที่จัดเก็บ

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: RDBMS (Oracle, MySQL, SQL Server), Shell Scripting, Performance Tuning
- Soft Skills: ความรับผิดชอบสูง, ทนทานต่อความกดดันเมื่อระบบมีปัญหา

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: มักเติบโตมาจาก IT Support หรือ System Admin แล้วสอบใบเซอร์เฉพาะทางของ Database

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 25,000-40,000 บาท / Senior 60,000-120,000+ บาท
- แนวโน้มความต้องการในตลาด: ทรงตัวเนื่องจากถูกแทนที่ด้วย Cloud Database แต่คนที่เก่ง Cloud DBA ยังเป็นที่ต้องการสูง
