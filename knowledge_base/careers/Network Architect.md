# อาชีพ: Network Architect

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ออกแบบโครงข่ายการสื่อสารระดับสูง (Data Center หรือโครงข่ายข้ามประเทศ)
- ชีวิตประจำวัน (Day-to-day): วางแผนโครงสร้าง Network เพื่อรองรับการขยายสาขา, วางระบบ Redundancy

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Advanced Routing Protocols, SD-WAN, Network Design
- Soft Skills: การบริหารจัดการโครงการ, วิสัยทัศน์

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: เติบโตมาจาก Network Engineer + ใบเซอร์ระดับสูงเช่น CCIE
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องมีประสบการณ์สายเน็ตเวิร์กอย่างโชกโชน

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Senior/Lead Level 90,000-180,000+ บาท
- แนวโน้มความต้องการในตลาด: เป็นที่ต้องการในธุรกิจโทรคมนาคมและ Data Center
