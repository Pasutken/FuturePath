# อาชีพ: MLOps Engineer (Machine Learning Operations)

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ดูแลวงจรชีวิตของ AI/ML โมเดลตั้งแต่เทรนเสร็จ ไปจนถึงการใช้งานจริงและเฝ้าระวัง
- ชีวิตประจำวัน (Day-to-day): วางระบบ CI/CD สำหรับ ML โมเดล, มอนิเตอร์ประสิทธิภาพของโมเดล, จัดการระบบคลาวด์

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Docker, Kubernetes, CI/CD, MLflow, Cloud Services, Python
- Soft Skills: ทักษะการจัดการระบบสไตล์ DevOps

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิศวกรรมคอมพิวเตอร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: มักเติบโตมาจากการเป็น DevOps หรือ ML Engineer ก่อน

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 45,000-70,000 บาท / Senior 110,000-200,000+ บาท
- แนวโน้มความต้องการในตลาด: เป็นอาชีพใหม่ที่กำลังเป็นที่ต้องการสุดๆ เพื่อนำโมเดล AI มาใช้จริงในระดับโปรดักชัน
