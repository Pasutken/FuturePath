# อาชีพ: Network Security Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: โฟกัสเฉพาะเรื่องความปลอดภัยของระบบเครือข่ายและการรับส่งข้อมูลโดยเฉพาะ
- ชีวิตประจำวัน (Day-to-day): คอนฟิก VPN, บริหารจัดการ IPS/IDS, วิเคราะห์ Packet ข้อมูล

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Advanced Networking, VPN Protocols, Network Packet Analysis
- Soft Skills: การคิดแบบฉุกเฉินเมื่อถูกโจมตีทางเครือข่าย

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: สายเน็ตเวิร์ก
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: สอบใบเซอร์สาย Security ของแบรนด์อุปกรณ์นั้นๆ เช่น CCNP Security

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 35,000-55,000 บาท / Senior 80,000-130,000+ บาท
- แนวโน้มความต้องการในตลาด: โตไปพร้อมๆ กับสาย Network เป็นหัวใจสำคัญของการทำงานทางไกลให้ปลอดภัย
