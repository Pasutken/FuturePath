# อาชีพ: NLP (Natural Language Processing) Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: สอนให้คอมพิวเตอร์เข้าใจและประมวลผลภาษามนุษย์ (เสียงและข้อความ)
- ชีวิตประจำวัน (Day-to-day): สร้างแชทบอท (Chatbot), ระบบแปลภาษา, ระบบวิเคราะห์อารมณ์จากข้อความ

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Python, NLP Libraries (NLTK, spaCy, Hugging Face), Machine Learning
- Soft Skills: ความเข้าใจความซับซ้อนของภาษา (Syntax, Semantics)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, ภาษาศาสตร์คอมพิวเตอร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: หากมาจากสายภาษาศาสตร์ ต้องฝึกเขียน Python และ Machine Learning อย่างหนัก

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 40,000-60,000 บาท / Senior 100,000-160,000+ บาท
- แนวโน้มความต้องการในตลาด: เติบโตอย่างมากจากการมาถึงของยุค LLMs (Large Language Models)
