# อาชีพ: Software Architect

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ออกแบบโครงสร้างสถาปัตยกรรมระดับสูงของซอฟต์แวร์
- ชีวิตประจำวัน (Day-to-day): เลือกเทคโนโลยีที่จะใช้ในองค์กร, วางโครงสร้างระบบเพื่อรองรับผู้ใช้จำนวนมาก (Scalability), ให้คำปรึกษาทีม Dev

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: System Design, Microservices, Cloud Architecture, เชี่ยวชาญหลายภาษาโปรแกรมมิ่ง
- Soft Skills: ภาวะผู้นำ (Leadership), การมองภาพรวม (Big Picture Thinking)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, วิศวกรรมคอมพิวเตอร์ (ต้องมีประสบการณ์สาย Dev หลายปี)
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ยากที่จะข้ามสายมาโดยตรง ต้องไต่เต้ามาจากตำแหน่ง Software Developer

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Senior/Lead Level 120,000-250,000+ บาท
- แนวโน้มความต้องการในตลาด: ขาดแคลนอย่างหนัก เป็นตำแหน่งระดับสูงที่ต้องการประสบการณ์สูง
