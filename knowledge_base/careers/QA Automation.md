# อาชีพ: QA Automation (Quality Assurance Automation Engineer / SDET)

## 1. บทบาทและหน้าที่ (Overview)

- **สรุปสั้นๆ ว่าอาชีพนี้ทำหน้าที่อะไร:** QA Automation ทำหน้าที่เขียนโค้ดและสร้างสคริปต์เพื่อ "ทดสอบซอฟต์แวร์โดยอัตโนมัติ" แทนการใช้คนคลิกทดสอบทีละขั้นตอน (Manual) เป้าหมายคือเพื่อค้นหาข้อผิดพลาด (Bugs) ตรวจสอบความถูกต้องของระบบทั้งหน้าบ้าน (Frontend) และหลังบ้าน (API/Backend) และช่วยให้กระบวนการอัปเดตซอฟต์แวร์ทำได้รวดเร็ว แม่นยำ และทำซ้ำได้ตลอดเวลาตามแนวทางปฏิบัติแบบ DevOps

- **ชีวิตประจำวัน (Day-to-day) ต้องเจอกับงานลักษณะไหน:** งานในแต่ละวันจะมีลักษณะคล้ายโปรแกรมเมอร์ผสมกับนักวิเคราะห์คุณภาพ เช่น การเขียนสคริปต์ทดสอบ (Automated Test Scripts), การสร้างและบำรุงรักษาโครงสร้างพื้นฐานสำหรับการทดสอบ (Test Frameworks), การนำชุดทดสอบไปผูกเข้ากับระบบ CI/CD Pipeline (เพื่อให้ระบบรันเทสอัตโนมัติทุกครั้งที่ Developer อัปโหลดโค้ดใหม่), การตรวจสอบรายงานผลการรันเทส (Test Execution Reports), การบันทึกและแจ้งข้อผิดพลาด (Defect/Bug Reporting) ผ่านระบบอย่าง Jira และประชุมร่วมกับ Developer เพื่อหาสาเหตุของปัญหา

## 2. ทักษะที่จำเป็น (Required Skills)

- **Hard Skills:** - ภาษาโปรแกรมมิ่ง (ต้องเขียนโค้ดได้): Python, Java, JavaScript/TypeScript, C# (ขึ้นอยู่กับ Tech Stack ขององค์กร)
  - เครื่องมือทดสอบอัตโนมัติ (Automation Tools): Selenium, Cypress, Playwright, Robot Framework (สำหรับ Web) / Appium (สำหรับ Mobile)
  - การทดสอบ API (API Testing): Postman, REST Assured
  - เครื่องมือ CI/CD และ Version Control: Git, Jenkins, GitLab CI, GitHub Actions
  - ความรู้เสริม: ความเข้าใจคำสั่ง SQL เบื้องต้นสำหรับการตรวจสอบข้อมูลในฐานข้อมูล (Database Validation)

- **Soft Skills:** - ความใส่ใจในรายละเอียดสูงมาก (High Attention to Detail) เพื่อดักจับข้อผิดพลาดที่คนอื่นมองข้าม
  - ทักษะการคิดวิเคราะห์และแก้ปัญหา (Analytical & Problem Solving)
  - ทักษะการสื่อสาร (Communication) โดยเฉพาะการแจ้งข้อผิดพลาดให้ Developer ทราบอย่างมีศิลปะและชัดเจน พร้อมข้อมูลสนับสนุน (Steps to reproduce, Logs)
  - ความคิดเชิงระบบ (Systems Thinking) เพื่อมองเห็นผลกระทบของการแก้ไขโค้ดในจุดหนึ่งต่อระบบภาพรวม

## 3. เส้นทางการศึกษา (Educational Pathway)

- **สายตรง:** สาขาวิทยาการคอมพิวเตอร์ (Computer Science), วิศวกรรมคอมพิวเตอร์ (Computer Engineering), วิศวกรรมซอฟต์แวร์ (Software Engineering) และเทคโนโลยีสารสนเทศ (IT) เนื่องจากอาชีพนี้ต้องการพื้นฐานการเขียนโปรแกรม (Coding) และโครงสร้างข้อมูล (Data Structures) ที่แข็งแรง

- **จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง:** อาชีพนี้มักเกิดจากการเติบโตหรือย้ายสายมาจากตำแหน่ง Manual QA / Software Tester ที่ต้องการอัปสกิล หรือ Developer ที่เปลี่ยนสายมาเน้นด้านคุณภาพระบบ (SDET - Software Development Engineer in Test) สิ่งที่ต้องไปเรียนเพิ่ม (Top-up) สำหรับคนย้ายสายคือ "การเขียนโปรแกรม" และ "การใช้ Automation Framework" สิ่งสำคัญในการสมัครงานคือการมี **GitHub Repository** หรือ **Portfolio** ที่เก็บผลงานการเขียนสคริปต์ทดสอบ (เช่น การเขียนโค้ดล็อกอินหน้าเว็บแบบอัตโนมัติ หรือดึงข้อมูลจาก API มาตรวจสอบค่า)

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)

- **ช่วงเงินเดือนสำหรับเด็กจบใหม่และคนมีประสบการณ์:** (อ้างอิงข้อมูลจริงจากรายงานตลาดแรงงาน Tech ในไทย เช่น Adecco Salary Guide, PRTR, Techsauce และ JobsDB)
  - **Junior (ประสบการณ์ 1-3 ปี):** ประมาณ 35,000 - 55,000 บาท/เดือน (หมายเหตุ: ฐานเงินเดือนจะสูงกว่า Manual QA อย่างมีนัยสำคัญ เด็กจบใหม่ที่จะได้ตำแหน่งนี้มักต้องมีทักษะการเขียนโค้ดที่ดีระดับหนึ่ง)
  - **Mid-Level (ประสบการณ์ 3-5 ปี):** ประมาณ 60,000 - 90,000 บาท/เดือน
  - **Senior / Lead / SDET (ประสบการณ์ 5 ปีขึ้นไป):** ประมาณ 90,000 - 150,000+ บาท/เดือน (หากสามารถวางสถาปัตยกรรมการทดสอบ - Test Architecture ให้กับองค์กรขนาดใหญ่ได้ เงินเดือนสามารถเทียบเท่าหรือสูงกว่า Senior Developer บางตำแหน่ง)

- **แนวโน้มความต้องการในตลาด:** "สูงมากและขาดแคลนอย่างหนัก" ในตลาดแรงงานไทย เนื่องจากองค์กรส่วนใหญ่กำลังปรับตัวเข้าสู่การทำงานแบบ Agile และ CI/CD ซึ่งไม่สามารถใช้คนทดสอบแบบ Manual ได้ทันรอบการปล่อยซอฟต์แวร์อีกต่อไป อย่างไรก็ตาม ตลาดกลับประสบปัญหาขาดแคลนบุคลากร เพราะหาคนที่มีทักษะผสมผสาน (Hybrid) ระหว่าง "กระบวนการคิดแบบ QA" และ "ความสามารถในการเขียนโค้ดแบบ Developer" ได้ยาก ทำให้ QA Automation เป็นตำแหน่งที่บริษัทเทคโนโลยียอมทุ่มเงินซื้อตัวสูงมาก
