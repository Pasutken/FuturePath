# อาชีพ: IT Operations Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: สายสนับสนุนประจำวัน ดูแลภาพรวมของเครื่องมือและระบบ IT ภายในออฟฟิศ
- ชีวิตประจำวัน (Day-to-day): มอนิเตอร์ระบบ, ทำงานตาม Service Request, จัดการ License ซอฟต์แวร์

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: OS Troubleshooting, Office 365/Google Workspace Admin, Ticketing System
- Soft Skills: Service Mind ขั้นสูง, การสื่อสารกับคนที่ไม่เก่ง IT ให้เข้าใจง่าย

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: IT, คอมพิวเตอร์ธุรกิจ
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เป็นจุดเริ่มต้นที่ดีที่สุดของคนย้ายสายมา IT เรียนรู้ผ่านการปฏิบัติจริงได้

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 18,000-30,000 บาท / Senior 45,000-70,000 บาท
- แนวโน้มความต้องการในตลาด: ทรงตัว ทุกบริษัทยังต้องการคน Support พนักงาน
