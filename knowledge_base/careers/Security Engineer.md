# อาชีพ: Security Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้ลงมือสร้างและคอนฟิกระบบรักษาความปลอดภัย (เป็นสาย Implementer)
- ชีวิตประจำวัน (Day-to-day): ติดตั้งระบบป้องกัน, ตั้งค่า Firewall/WAF, เขียนสคริปต์อัตโนมัติอุดช่องโหว่

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Firewall Administration, Scripting (Python/Bash), Endpoint Security, Cloud Security
- Soft Skills: ทักษะทางวิศวกรรม, การทำงานเชิงรุก

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิศวกรรมคอมพิวเตอร์, IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: มักย้ายมาจาก System/Network Engineer ที่ต่อยอดความรู้ด้าน Security

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 35,000-55,000 บาท / Senior 80,000-140,000+ บาท
- แนวโน้มความต้องการในตลาด: ต้องการสูง องค์กรต้องการคนที่ปฏิบัติการติดตั้งเครื่องมือป้องกันได้จริง
