# อาชีพ: Site Reliability Engineer (SRE)

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ใช้แนวทางการเขียนซอฟต์แวร์ มาแก้ปัญหาระบบปฏิบัติการเพื่อให้ระบบมีความเสถียร 99.99%
- ชีวิตประจำวัน (Day-to-day): ตรวจสอบระบบ Monitoring, เขียนโค้ดเพื่อแก้ปัญหาระบบอัตโนมัติ, สืบสวนสาเหตุเวลาระบบล่ม

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Programming (Go, Python), Systems Architecture, Cloud/Networking, Monitoring Tools
- Soft Skills: ความนิ่งภายใต้ความกดดัน, การแก้ไขปัญหาที่รากเหง้า (Root Cause Analysis)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, วิศวกรรมคอมพิวเตอร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: มักมาจากสาย Software Engineer ที่ชอบงานสเกลระดับโครงสร้างพื้นฐาน

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 40,000-70,000 บาท / Senior 100,000-200,000+ บาท
- แนวโน้มความต้องการในตลาด: ตำแหน่งคู่ขนานของ DevOps บริษัทยักษ์ใหญ่ต้องการตัวสูง
