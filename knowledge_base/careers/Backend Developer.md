# อาชีพ: Backend Developer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: สร้างระบบหลังบ้าน จัดการฐานข้อมูล และเขียน API เพื่อให้ระบบทำงานได้
- ชีวิตประจำวัน (Day-to-day): ออกแบบฐานข้อมูล, เขียนลอจิกของระบบ, จัดการความปลอดภัยและประสิทธิภาพของเซิร์ฟเวอร์

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Node.js, Python, Java, Go, PHP, SQL/NoSQL
- Soft Skills: การคิดเชิงตรรกะ (Logical Thinking), การแก้ปัญหา

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิทยาการคอมพิวเตอร์, วิศวกรรมซอฟต์แวร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ต้องเข้าใจระบบการทำงานของ Server และ Database ทำโปรเจกต์สร้าง API ของตัวเอง

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 25,000-45,000 บาท / Senior 70,000-120,000+ บาท
- แนวโน้มความต้องการในตลาด: เป็นกระดูกสันหลังของทุกระบบ IT ความต้องการคงที่และสูงเสมอ
