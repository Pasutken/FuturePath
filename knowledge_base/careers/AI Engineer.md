# อาชีพ: AI Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: พัฒนาและสร้างระบบปัญญาประดิษฐ์ให้สามารถคิดหรือทำงานได้
- ชีวิตประจำวัน (Day-to-day): เทรน Deep Learning Models, ปรับแต่ง Neural Networks, พัฒนาโซลูชัน AI แบบ End-to-end

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Deep Learning Frameworks, Python, Mathematics & Linear Algebra ขั้นสูง
- Soft Skills: ความคิดสร้างสรรค์ในการแก้ปัญหา, การวิจัย (Research skill)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: ปริญญาโท/เอก ด้าน AI, วิทยาการคอมพิวเตอร์, คณิตศาสตร์ประยุกต์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ยากมากที่จะทำโดยไม่มีพื้นฐานคณิตศาสตร์และคอมพิวเตอร์เชิงลึก

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 45,000-80,000 บาท / Senior 120,000-200,000+ บาท
- แนวโน้มความต้องการในตลาด: เป็นอาชีพหัวหอกของการพัฒนาเทคโนโลยีอนาคต เป็นที่ต้องการสูงมาก
