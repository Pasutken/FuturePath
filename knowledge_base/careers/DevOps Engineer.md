# อาชีพ: DevOps Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: นำหลักการอัตโนมัติมาใช้เพื่อลดช่องว่างระหว่างทีมเขียนโค้ดและทีมดูแลเซิร์ฟเวอร์
- ชีวิตประจำวัน (Day-to-day): เขียน Script สร้างท่อ CI/CD, ดูแลระบบ Container (Docker), ทำ Infrastructure as Code (IaC)

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Git, CI/CD Tools (Jenkins/GitLab CI), Docker, Kubernetes, Linux, Terraform
- Soft Skills: การทลายกำแพงการทำงานระหว่างทีม, การสื่อสาร

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: วิศวกรรมคอมพิวเตอร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: สามารถข้ามสายมาจาก Developer หรือ System Admin ขอแค่มีทักษะเขียน Script และเข้าใจระบบ

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 35,000-60,000 บาท / Senior 90,000-180,000+ บาท
- แนวโน้มความต้องการในตลาด: เป็นตัวเร่งสปีดการทำงานให้ธุรกิจ จึงเป็นที่ต้องการอย่างล้นหลาม
