# อาชีพ: Data Analyst

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: วิเคราะห์ข้อมูลในอดีตและปัจจุบัน เพื่อตอบคำถามทางธุรกิจ
- ชีวิตประจำวัน (Day-to-day): ทำความสะอาดข้อมูล, ทำ Dashboard แสดงผล (Visualization), นำเสนอข้อมูลให้ทีม Business

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: SQL, Excel, BI Tools (Tableau, PowerBI), Python พื้นฐาน
- Soft Skills: การนำเสนอ (Presentation), ความเข้าใจเชิงธุรกิจ (Business Acumen)

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: สถิติ, บริหารธุรกิจ, เศรษฐศาสตร์, วิศวกรรมศาสตร์
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เปิดกว้างมาก ต้องอัปสกิล SQL และ BI Tools ให้แม่นยำเพื่อใช้ทำ Portfolio

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 25,000-40,000 บาท / Senior 60,000-100,000+ บาท
- แนวโน้มความต้องการในตลาด: สูงมาก เป็นตำแหน่งพื้นฐานที่ทุกองค์กรยุคใหม่ต้องมี
