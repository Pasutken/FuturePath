# อาชีพ: BI (Business Intelligence) Developer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: พัฒนาระบบรายงานและ Dashboard แบบอัตโนมัติ เพื่อให้ผู้บริหารดูสรุปผลประกอบการ
- ชีวิตประจำวัน (Day-to-day): เชื่อมต่อข้อมูลเข้า BI Tool, สร้างกราฟและตัวชี้วัด (KPIs) เชิงโต้ตอบ

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: PowerBI, Tableau, SQL ขั้นสูง, Data Warehousing
- Soft Skills: ความเข้าใจธุรกิจ (Business Acumen), UX/UI ทางด้าน Data

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: ระบบสารสนเทศ, บริหารธุรกิจ, IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: ทำ Portfolio สร้าง Dashboard จาก Dataset จริง (หาได้จากเว็บ open data)

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 30,000-45,000 บาท / Senior 70,000-110,000+ บาท
- แนวโน้มความต้องการในตลาด: เป็นที่ต้องการต่อเนื่อง เพราะธุรกิจต้องพึ่งพารายงานในการตัดสินใจ
