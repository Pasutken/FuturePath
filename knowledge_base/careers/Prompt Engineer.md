# อาชีพ: Prompt Engineer

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ผู้เขียนคำสั่ง (Prompt) เพื่อรีดประสิทธิภาพสูงสุดจาก Generative AI
- ชีวิตประจำวัน (Day-to-day): ทดสอบและปรับแต่ง Prompt ให้ AI ให้ผลลัพธ์ที่แม่นยำ, ออกแบบ Prompt Templates ให้คนในองค์กร

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: โครงสร้างภาษา, ความเข้าใจสถาปัตยกรรม LLM เบื้องต้น, Python พื้นฐาน
- Soft Skills: ตรรกะความคิดที่เป็นระบบ, ศิลปะการใช้ภาษา

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: ยังไม่มีสายตรงชัดเจน (ภาษาศาสตร์ หรือ วรรณกรรม สามารถต่อยอดได้ดี)
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เปิดรับทุกคน เพียงแค่ต้องลองใช้งานและทดลอง Prompt หลากหลายรูปแบบอย่างจริงจัง

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 25,000-40,000 บาท / Senior 60,000-100,000+ บาท (บางครั้งพ่วงอยู่ในตำแหน่งอื่น)
- แนวโน้มความต้องการในตลาด: เป็นทักษะที่ทุกคนควรมี แต่ในอนาคตอาจมีตำแหน่งเฉพาะทางเปิดรับมากขึ้น
