# อาชีพ: Security Operations Center (SOC) Analyst

## 1. บทบาทและหน้าที่ (Overview)
- สรุปสั้นๆ: ยามเฝ้าระวังภัยไซเบอร์ นั่งหน้าจอเฝ้าดูความผิดปกติในระบบแบบเรียลไทม์
- ชีวิตประจำวัน (Day-to-day): ดูหน้าจอ SIEM, ตรวจสอบ Alert ว่าเป็นภัยจริงหรือลวง, ดำเนินการบล็อกเบื้องต้น

## 2. ทักษะที่จำเป็น (Required Skills)
- Hard Skills: Log Analysis, Basic Incident Response, SIEM Tools
- Soft Skills: ความอดทน (ทำงานเป็นกะ), การตัดสินใจภายใต้ความกดดัน

## 3. เส้นทางการศึกษา (Educational Pathway)
- สายตรง: Cybersecurity, IT
- จบไม่ตรงสาย / อาชีพที่ไม่มีสาขาตรง: เป็น Entry-level ที่ดีมาก สอบใบเซอร์ CySA+ หรือปฏิบัติบนแพลตฟอร์ม Blue Team

## 4. โอกาสทางอาชีพและผลตอบแทน (Market & Salary)
- ช่วงเงินเดือน: Junior 25,000-40,000 บาท / Senior 60,000-100,000+ บาท
- แนวโน้มความต้องการในตลาด: ตำแหน่งเริ่มต้นของสาย Security ปัจจุบันองค์กรเริ่ม Outsource ให้บริการภายนอกดูแล
