# สาขาวิชา: วิทยาการคอมพิวเตอร์ (Computer Science - CS)

## 1. สาขานี้เรียนเกี่ยวกับอะไร? (Overview)
- ภาพรวมของสาขานี้: เน้นเจาะลึกทฤษฎี โครงสร้างข้อมูล อัลกอริทึม การเขียนโปรแกรม และการแก้ปัญหาซับซ้อน (เป็นสาขาหลักที่ไปได้เกือบทุกสายงาน)
- วิชาแกนหลักที่ต้องเจอ (Core Subjects): Data Structures & Algorithms, Theory of Computation, Operating Systems, Database Systems
- โปรเจกต์ที่มักจะได้ทำระหว่างเรียน: พัฒนา AI เบื้องต้น, การเขียนโปรแกรมแก้โจทย์อัลกอริทึม, หรือการสร้างเว็บไซต์ E-Commerce แบบ Full-Stack พร้อมระบบ Admin Dashboard เพื่อจัดการข้อมูล

## 2. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง? (Career Paths)
- อาชีพสายตรง: Software Developer (Frontend/Backend/Full Stack), System Analyst, Software Engineer
- อาชีพประยุกต์หรือข้ามสาย: Data Scientist, AI Engineer, DevOps Engineer

## 3. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน (Additional Skills)
- ใบรับรอง (Certifications) ที่ควรสอบ: AWS Certified Developer, Microsoft Certified: Azure Fundamentals
- เทคโนโลยีที่ควรฝึกฝนเอง: คลุกคลีกับระบบ Cloud Services และฝึกทำโจทย์โค้ดดิ้งบน LeetCode หรือ HackerRank
