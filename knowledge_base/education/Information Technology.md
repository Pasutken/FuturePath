# สาขาวิชา: เทคโนโลยีสารสนเทศ (Information Technology - IT)

## 1. สาขานี้เรียนเกี่ยวกับอะไร? (Overview)
- ภาพรวมของสาขานี้: เน้นการนำเทคโนโลยีไปประยุกต์ใช้งานจริงในองค์กร การจัดการเครือข่าย ฐานข้อมูล และระบบปฏิบัติการ
- วิชาแกนหลักที่ต้องเจอ (Core Subjects): IT Infrastructure, Database Management, Network Administration, Information Security
- โปรเจกต์ที่มักจะได้ทำระหว่างเรียน: วางระบบเซิร์ฟเวอร์จำลองสำหรับองค์กร, ออกแบบโครงสร้างฐานข้อมูลสำหรับการทำงานจริงในออฟฟิศ

## 2. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง? (Career Paths)
- อาชีพสายตรง: IT Support, System Administrator, IT Operations Engineer
- อาชีพประยุกต์หรือข้ามสาย: Cybersecurity Analyst, Cloud Engineer, System Analyst

## 3. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน (Additional Skills)
- ใบรับรอง (Certifications) ที่ควรสอบ: CompTIA A+, CompTIA Network+, ITIL Foundation
- เทคโนโลยีที่ควรฝึกฝนเอง: ฝึกใช้งานและตั้งค่าระบบ Cloud Infrastructure เบื้องต้น (Azure/AWS/GCP)
