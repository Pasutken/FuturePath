# สาขาวิชา: วิศวกรรมซอฟต์แวร์ (Software Engineering - SE)

## 1. สาขานี้เรียนเกี่ยวกับอะไร? (Overview)
- ภาพรวมของสาขานี้: เน้นกระบวนการพัฒนาซอฟต์แวร์อย่างเป็นระบบ การจัดการโปรเจกต์ (SDLC) การทดสอบระบบ และสถาปัตยกรรมซอฟต์แวร์
- วิชาแกนหลักที่ต้องเจอ (Core Subjects): Software Architecture, Software Testing & Quality Assurance, Agile Project Management
- โปรเจกต์ที่มักจะได้ทำระหว่างเรียน: ทำโปรเจกต์พัฒนาระบบสเกลใหญ่ร่วมกับทีม (จำลองสภาพแวดล้อมบริษัท) หรือสร้างแอปพลิเคชันที่มีระบบหลังบ้านเก็บยอดขายและข้อมูลการลงทะเบียน

## 2. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง? (Career Paths)
- อาชีพสายตรง: Software Developer, Software Tester (QA), Scrum Master, System Analyst, Software Engineer
- อาชีพประยุกต์หรือข้ามสาย: DevOps Engineer, Product Owner, IT Consultant

## 3. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน (Additional Skills)
- ใบรับรอง (Certifications) ที่ควรสอบ: ISTQB (สำหรับสาย QA/Tester), Scrum Master Certification (CSM)
- เทคโนโลยีที่ควรฝึกฝนเอง: การใช้งาน Docker, Kubernetes, และ CI/CD Tools อย่าง GitLab CI/Jenkins
