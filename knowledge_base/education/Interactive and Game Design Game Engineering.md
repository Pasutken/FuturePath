# สาขาวิชา: การออกแบบอินเทอร์แอคทีฟและเกม / วิศวกรรมเกม (Interactive and Game Design / Game Engineering)

## 1. สาขานี้เรียนเกี่ยวกับอะไร?
ภาพรวมของสาขานี้คือการผสมผสานระหว่าง "ศิลปะ (Art) และ เทคโนโลยี (Tech)" โดยระดับความเข้มข้นจะขึ้นอยู่กับชื่อและคณะที่สังกัด หากแบ่งตามสายงานจะพบว่า:
- สายวิศวกรรมเกม / การเขียนโปรแกรมเกม (Game Engineering / Game Programming): จะเน้นการเขียนโค้ด (Coding) และทฤษฎีระบบนิเวศของเกมเป็นหลัก เช่น การเขียนสถาปัตยกรรมเกม, การจัดการหน่วยความจำ, การเขียน AI ควบคุมพฤติกรรมตัวละครในเกม, การคำนวณฟิสิกส์ (Physics) และระบบเน็ตเวิร์กสำหรับการทำเกมออนไลน์แบบ Multiplayer
- สายการออกแบบเกมและอินเทอร์แอคทีฟ (Game and Interactive Design): จะเน้นการออกแบบระบบ (System Design), สุนทรียภาพ, และประสบการณ์ผู้ใช้ (UX) เช่น การวางกฎเกณฑ์ของเกม (Game Mechanics), การออกแบบด่าน (Level Design), การเล่าเรื่อง (Storytelling) รวมถึงการสร้างสื่อโต้ตอบอื่นๆ เช่น AR (Augmented Reality) และ VR (Virtual Reality)

## 2. วิชาแกนหลักที่ต้องเจอ (Core Subjects)
หลักสูตรในไทยมักจะครอบคลุมตั้งแต่กระบวนการคิด (Pre-production) ไปจนถึงการพัฒนา (Production) ตัวอย่างวิชาเรียนและโปรเจกต์ที่สำคัญ ได้แก่:

### รายวิชาเด่น
- Game Engine Programming: การเขียนโปรแกรมและพัฒนาเกมผ่านเอนจินยอดฮิต เช่น Unity (ใช้ C#) หรือ Unreal Engine (ใช้ C++ / Blueprints)
- Game Design and Mechanics: การออกแบบระบบการเล่น, ความสมดุลของเกม (Game Balance), และจิตวิทยาผู้เล่น
- 3D Modeling and Animation: การสร้างโมเดล 3 มิติ, การขึ้นโครง (Rigging), และการทำแอนิเมชันสำหรับเกม
- Interactive Media & AR/VR Development: การพัฒนาสื่อปฏิสัมพันธ์ หรือพื้นที่โลกเสมือนจริงที่นำไปใช้ได้ทั้งในเกมและในภาคธุรกิจ
- User Interface and User Experience Design (UI/UX): การออกแบบหน้าจอเมนูและการโต้ตอบเพื่อให้ผู้เล่นใช้งานได้ลื่นไหลและเข้าใจง่าย

### โปรเจกต์ที่มักจะได้ทำระหว่างเรียน
- Game Jam / Mini-game Project: การสร้างเกมขนาดเล็กให้เล่นได้จริงภายในระยะเวลาจำกัด
- Interactive Exhibition: การทำสื่อโต้ตอบผ่านเซ็นเซอร์ (เช่น Kinect, Leap Motion) สำหรับงานอีเวนต์
- Capstone Project / Senior Project: การจำลองการทำงานเป็น Game Studio ขนาดเล็ก โดยนักศึกษาจะต้องรวมทีมกันแบ่งหน้าที่ (Programmer, Artist, Game Designer) เพื่อพัฒนาเกมที่สามารถนำไปวางขายหรือประกวดได้จริง

## 3. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง?

### อาชีพสายตรง (จบปุ๊บ ทำตำแหน่งอะไรได้บ้าง?)
- Game Programmer / Developer: นักพัฒนาโปรแกรมเกม (คนเขียนโค้ดสร้างระบบ)
- Game Designer: นักออกแบบเกม (คนกำหนดกติกา, ด่าน, และความสนุกของเกม)
- Level Designer: นักออกแบบด่านและสิ่งแวดล้อมภายในเกม
- Technical Artist (TA): ตำแหน่งลูกผสมที่ต้องรู้ทั้งการทำกราฟิกและการเขียนโค้ด เพื่อช่วยแก้ปัญหาและปรับแต่งภาพในเกมให้รันได้อย่างลื่นไหล (เป็นที่ต้องการตัวสูงมาก)
- 3D Artist / Animator: ศิลปินผู้สร้างโมเดล ฉาก และแอนิเมชันสำหรับเกม
- Game QA / Tester: ผู้ทดสอบระบบเกมเพื่อหาบั๊ก (Bug) ก่อนปล่อยสู่ตลาด

### อาชีพประยุกต์หรือข้ามสาย
- AR/VR / Metaverse Developer: นักพัฒนาโลกเสมือนจริงสำหรับองค์กร ธุรกิจอสังหาริมทรัพย์ หรือการแพทย์
- UI/UX Designer: นักออกแบบประสบการณ์ผู้ใช้งานสำหรับเว็บไซต์หรือแอปพลิเคชัน (ทักษะจากเกมสามารถประยุกต์ใช้กับแอปพลิเคชันทั่วไปได้ดีมาก)
- Interactive Media Designer: นักออกแบบสื่อโต้ตอบสำหรับงานนิทรรศการ งานคอนเสิร์ต หรือพิพิธภัณฑ์
- Software Engineer / Frontend Developer: หากมีความเชี่ยวชาญเรื่องการเขียนโค้ดและโครงสร้างข้อมูล สามารถข้ามไปทำงานพัฒนาซอฟต์แวร์หรือเว็บไซต์ปกติได้

## 4. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน
วงการเกมและสื่ออินเทอร์แอคทีฟมีการเปลี่ยนแปลงเทคโนโลยีที่ไวมาก ทักษะและสิ่งที่ควรมีเพื่อเพิ่มโอกาสได้งานในยุคปัจจุบัน คือ:

### พอร์ตโฟลิโอ (Portfolio)
- ในสายงานนี้ ใบปริญญาไม่สำคัญเท่าผลงาน ต้องมีผลงานเกมที่ทำเสร็จและเล่นได้จริง (Playable Demo) อัปโหลดไว้บนแพลตฟอร์มอย่าง Itch.io หรือมีซอร์สโค้ดให้ดูบน GitHub

### ใบรับรอง (Certifications) ที่แนะนำ
- Unity Certified User / Associate / Professional (ขึ้นอยู่กับระดับความเชี่ยวชาญ)
- Unreal Engine Certification (ช่วยให้โปรไฟล์โดดเด่นมาก โดยเฉพาะสำหรับการสมัครงานใน Studio เกมระดับ AA หรือ AAA)

### เทคโนโลยีที่ควรฝึกฝนเอง
- Generative AI สำหรับเกม: การใช้ AI ช่วยสร้าง Asset หรือคอนเซปต์อาร์ตเบื้องต้น (เช่น Midjourney, Stable Diffusion) หรือ AI สำหรับเขียนโค้ด (Copilot) เพื่อทุ่นแรง
- Multiplayer / Network Programming: ทักษะการทำเกมออนไลน์ (เช่น การใช้ Photon Network หรือ AWS GameLift) เป็นทักษะขั้นสูงที่สตูดิโอเกมต้องการตัวสูง
- Optimization Skills: ทักษะในการรีดประสิทธิภาพของเกมให้สามารถรันบนอุปกรณ์มือถือสเปกต่ำหรือแว่น VR ได้โดยที่เครื่องไม่กระตุก
