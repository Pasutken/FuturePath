# สาขาวิชา: วิศวกรรมคอมพิวเตอร์ (Computer Engineering - CPE)

## 1. สาขานี้เรียนเกี่ยวกับอะไร? (Overview)
- ภาพรวมของสาขานี้: เรียนคลุมทั้งฮาร์ดแวร์ ซอฟต์แวร์ สถาปัตยกรรมคอมพิวเตอร์ ไมโครคอนโทรลเลอร์ และ IoT
- วิชาแกนหลักที่ต้องเจอ (Core Subjects): Digital Logic Design, Microprocessors, Embedded Systems, Computer Networks
- โปรเจกต์ที่มักจะได้ทำระหว่างเรียน: สร้างหุ่นยนต์อัตโนมัติ, ระบบ Smart Home (IoT), ออกแบบและบัดกรีแผงวงจร

## 2. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง? (Career Paths)
- อาชีพสายตรง: Embedded System Engineer, Network Engineer, Hardware Engineer
- อาชีพประยุกต์หรือข้ามสาย: Software Developer, DevOps Engineer, Site Reliability Engineer (SRE)

## 3. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน (Additional Skills)
- ใบรับรอง (Certifications) ที่ควรสอบ: CCNA (Cisco Certified Network Associate) หรือใบเซอร์สาย Cloud
- เทคโนโลยีที่ควรฝึกฝนเอง: ฝึกเขียน C/C++ สำหรับ Hardware ให้คล่อง ควบคู่ไปกับ Python สำหรับเขียนสคริปต์อัตโนมัติ
