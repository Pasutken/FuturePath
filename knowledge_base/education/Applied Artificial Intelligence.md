# สาขาวิชา: ปัญญาประดิษฐ์ประยุกต์ (Applied Artificial Intelligence)

## 1. สาขานี้เรียนเกี่ยวกับอะไร? (Overview)
- ภาพรวมของสาขานี้: เน้นการสร้างโมเดล Machine Learning, Deep Learning และเทคโนโลยีอย่าง RAG หรือ Generative AI
- วิชาแกนหลักที่ต้องเจอ (Core Subjects): Neural Networks, Natural Language Processing (NLP), Computer Vision, AI Ethics
- โปรเจกต์ที่มักจะได้ทำระหว่างเรียน: สร้างแชทบอทตอบคำถามลูกค้าอัตโนมัติ, พัฒนาระบบแยกแยะใบหน้าหรือวัตถุจากวิดีโอ

## 2. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง? (Career Paths)
- อาชีพสายตรง: AI Engineer, Machine Learning Engineer, NLP Engineer, Computer Vision Engineer
- อาชีพประยุกต์หรือข้ามสาย: Data Scientist, Python Developer, MLOps Engineer

## 3. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน (Additional Skills)
- ใบรับรอง (Certifications) ที่ควรสอบ: TensorFlow Developer Certificate, AWS Certified Machine Learning
- เทคโนโลยีที่ควรฝึกฝนเอง: ติดตามเปเปอร์งานวิจัย AI ล่าสุดเสมอ, ลองใช้งานโมเดลโอเพนซอร์สบน Hugging Face
