# สาขาวิชา: ความมั่นคงปลอดภัยทางไซเบอร์ / วิทยาการเข้ารหัสลับ (Cybersecurity / Cryptography)

## 1. สาขานี้เรียนเกี่ยวกับอะไร?
ภาพรวมของสาขานี้คือการเรียนรู้เพื่อ **"ปกป้องและรับมือภัยคุกคามทางดิจิทัล"** โดยบูรณาการความรู้ด้าน **ระบบเน็ตเวิร์ก (Networking)**, **การเขียนโค้ด (Coding)**, และ **นโยบายความปลอดภัย (Security Policy)** เข้าด้วยกัน การเรียนจะเน้นไปที่การวิเคราะห์ช่องโหว่ การเข้ารหัสข้อมูลเพื่อความลับ และการตอบสนองต่อเหตุการณ์ละเมิดความปลอดภัย:
- **สายความมั่นคงปลอดภัยทางไซเบอร์ (Cybersecurity):** เน้นที่ระบบโครงสร้างพื้นฐาน การตั้งค่าไฟร์วอลล์ (Firewall) การตรวจสอบและเฝ้าระวังระบบเครือข่าย การจำลองการเจาะระบบเพื่อหาช่องโหว่ (Penetration Testing) และการจัดการความเสี่ยงตามกฎหมายหรือมาตรฐาน (เช่น ISO 27001, พ.ร.บ. ไซเบอร์ของไทย)
- **สายวิทยาการเข้ารหัสลับ (Cryptography):** เน้นทฤษฎีทางคณิตศาสตร์และวิทยาการคอมพิวเตอร์ที่ใช้ในการสร้างอัลกอริทึมเข้ารหัสและถอดรหัสข้อมูล (Encryption/Decryption) เช่น RSA, AES, Hashing รวมถึงเทคโนโลยีบล็อกเชน (Blockchain) และลายมือชื่อดิจิทัล (Digital Signature)

## 2. วิชาแกนหลักที่ต้องเจอ (Core Subjects)
หลักสูตรในไทยจะครอบคลุมทั้งฝั่งการป้องกัน (Blue Team) และฝั่งการโจมตีจำลอง (Red Team) ตัวอย่างวิชาเรียนและโปรเจกต์ที่สำคัญ ได้แก่:

### รายวิชาเด่น
- Network and System Security: การรักษาความปลอดภัยในระดับเครือข่ายและระบบปฏิบัติการ (Windows/Linux)
- Cryptography and Data Security: ทฤษฎีการเข้ารหัสลับขั้นพื้นฐานและขั้นสูง การจัดการคีย์ (Key Management)
- Ethical Hacking / Penetration Testing: การเจาะระบบอย่างมีจริยธรรมเพื่อค้นหาและอุดช่องโหว่ของเว็บแอปพลิเคชันหรือเซิร์ฟเวอร์
- Digital Forensics / Cyber Investigation: นิติวิทยาศาสตร์ดิจิทัล การเก็บรวบรวมหลักฐานทางคอมพิวเตอร์หลังเกิดเหตุการณ์โจมตี (Incident Response)
- Information Security Management and Laws: กฎหมายเทคโนโลยีสารสนเทศของไทย (เช่น พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล - PDPA, พ.ร.บ. การรักษาความมั่นคงปลอดภัยไซเบอร์) และมาตรฐานความปลอดภัยสากล

### โปรเจกต์ที่มักจะได้ทำระหว่างเรียน
- Capture The Flag (CTF) Competitions: การแข่งขันจำลองสถานการณ์เพื่อค้นหาธง (ช่องโหว่) ในระบบที่กำหนด ซึ่งเป็นภาคปฏิบัติที่สำคัญมากในสายนี้
- Vulnerability Assessment Project: การทำโปรเจกต์สแกนและประเมินช่องโหว่ของระบบจำลอง หรือระบบขององค์กร (โดยได้รับอนุญาต) พร้อมจัดทำรายงานเสนอแนะวิธีแก้ไข
- Secure Software Development Lifecycle (SSDLC): การพัฒนาระบบหรือแอปพลิเคชันที่มีการฝังกระบวนการทดสอบความปลอดภัยตั้งแต่ขั้นตอนแรกของการเขียนโค้ด

## 3. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง?

### อาชีพสายตรง (จบปุ๊บ ทำตำแหน่งอะไรได้บ้าง?)
- SOC Analyst (Security Operations Center Analyst): นักวิเคราะห์ความปลอดภัย ทำหน้าที่เฝ้าระวังและแจ้งเตือนเมื่อพบความผิดปกติในระบบ (สาย Blue Team)
- Penetration Tester / Ethical Hacker: ผู้ทดสอบเจาะระบบ (สาย Red Team)
- Security Engineer: วิศวกรความปลอดภัยทางไซเบอร์ ผู้ติดตั้งและวางระบบรักษาความปลอดภัย เช่น Firewall, IPS/IDS
- Digital Forensics Investigator: ผู้ตรวจสอบและวิเคราะห์หลักฐานทางดิจิทัล (มักทำงานร่วมกับหน่วยงานบังคับใช้กฎหมายหรือบริษัทที่ปรึกษา)
- Cryptographer: นักวิทยาการเข้ารหัสลับ (ในไทยมักแฝงอยู่ในตำแหน่ง Security Researcher หรือ Blockchain Developer)

### อาชีพประยุกต์หรือข้ามสาย
- IT Auditor / Security Consultant: ผู้ตรวจสอบระบบสารสนเทศและให้คำปรึกษาด้านมาตรฐานความปลอดภัย (เช่น ตรวจสอบว่าระบบเป็นไปตาม PDPA หรือ ISO 27001 หรือไม่)
- Network Engineer / System Administrator: วิศวกรเครือข่ายหรือผู้ดูแลระบบ ที่มีความเชี่ยวชาญพิเศษด้านความปลอดภัย
- Blockchain / Smart Contract Developer: นักพัฒนาเทคโนโลยีบล็อกเชน ซึ่งต้องใช้พื้นฐานด้าน Cryptography อย่างมาก

## 4. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน
สายงาน Cybersecurity เป็นสายที่ให้ความสำคัญกับ **"ใบรับรองวิชาชีพ (Certifications)"** มากทัดเทียมกับหรือมากกว่าใบปริญญา ทักษะและสิ่งที่ควรมีคือ:

### ใบรับรอง (Certifications) ที่แนะนำและตลาดแรงงานไทยต้องการสูง
- ระดับเริ่มต้น (Entry-level): CompTIA Security+, CEH (Certified Ethical Hacker)
- ระดับปฏิบัติการเฉพาะทาง: eJPT, OSCP (Offensive Security Certified Professional - สายเจาะระบบ), CySA+ (สายป้องกัน)
- ระดับบริหาร/จัดการ (มักต้องมีประสบการณ์ทำงานก่อน): CISSP, CISA, CISM

### เทคโนโลยีที่ควรฝึกฝนเอง
- ระบบปฏิบัติการ Linux (โดยเฉพาะ Kali Linux): เป็นเครื่องมือพื้นฐานที่จำเป็นมากสำหรับงาน Cybersecurity
- Scripting Languages: การเขียนโปรแกรมด้วย Python, Bash, หรือ PowerShell เพื่อสร้างเครื่องมืออัตโนมัติ (Automation Tools) ในการสแกนระบบหรือวิเคราะห์ Log
- Cloud Security: ความเข้าใจระบบรักษาความปลอดภัยบนคลาวด์ (เช่น AWS, Azure, Google Cloud) เนื่องจากองค์กรในไทยส่วนใหญ่ย้ายระบบขึ้นคลาวด์แล้ว
- การใช้เครื่องมือด้านความปลอดภัย (Security Tools): เช่น Wireshark (วิเคราะห์ทราฟฟิกเน็ตเวิร์ก), Nmap, Burp Suite (ทดสอบเว็บ), และ SIEM Tools (เช่น Splunk หรือ Elastic)
