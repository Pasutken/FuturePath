# สาขาวิชา: วิศวกรรมข้อมูล (Data Engineering)

## 1. สาขานี้เรียนเกี่ยวกับอะไร? (Overview)
- ภาพรวมของสาขานี้: เน้นการสร้างระบบจัดเก็บข้อมูล โครงสร้างพื้นฐาน และระบบท่อส่งข้อมูล (Data Pipeline)
- วิชาแกนหลักที่ต้องเจอ (Core Subjects): Big Data Technologies (Hadoop/Spark), Database Architecture, Cloud Computing, ETL Processes
- โปรเจกต์ที่มักจะได้ทำระหว่างเรียน: สร้าง Data Pipeline ดึงข้อมูลมหาศาลแบบ Real-time, ออกแบบ Data Warehouse ในระดับองค์กร

## 2. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง? (Career Paths)
- อาชีพสายตรง: Data Engineer, Big Data Architect, Database Administrator (DBA)
- อาชีพประยุกต์หรือข้ามสาย: Cloud Engineer, Backend Developer

## 3. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน (Additional Skills)
- ใบรับรอง (Certifications) ที่ควรสอบ: AWS Certified Data Analytics, Google Cloud Professional Data Engineer
- เทคโนโลยีที่ควรฝึกฝนเอง: ฝึกใช้งาน Apache Airflow, Kafka, และการจัดการระบบฐานข้อมูลแบบกระจายศูนย์
