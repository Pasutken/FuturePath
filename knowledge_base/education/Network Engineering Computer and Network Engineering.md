# สาขาวิชา: วิศวกรรมเครือข่าย / วิศวกรรมคอมพิวเตอร์และเครือข่าย (Network Engineering / Computer and Network Engineering)

## 1. สาขานี้เรียนเกี่ยวกับอะไร?
ภาพรวมของสาขานี้คือการเรียนรู้เกี่ยวกับ **"โครงสร้างพื้นฐานของการสื่อสารข้อมูล"** (Infrastructure) ทั้งในระดับฮาร์ดแวร์และซอฟต์แวร์ เพื่อให้คอมพิวเตอร์ อุปกรณ์พกพา และเซิร์ฟเวอร์สามารถเชื่อมต่อและรับส่งข้อมูลกันได้อย่างรวดเร็ว เสถียร และปลอดภัย ในประเทศไทย สาขานี้มักจะอยู่ในคณะวิศวกรรมศาสตร์ (วิศวกรรมคอมพิวเตอร์ หรือ วิศวกรรมโทรคมนาคม) หรือคณะเทคโนโลยีสารสนเทศ โดยแบ่งความเน้นได้ดังนี้:
- **สายออกแบบและจัดการเครือข่าย (Network Design & Administration):** เน้นการวางระบบ LAN, WAN, การตั้งค่าอุปกรณ์เครือข่ายระดับองค์กร (Router, Switch, Firewall) และการบริหารจัดการแบนด์วิดท์ (Bandwidth)
- **สายโครงสร้างพื้นฐานคลาวด์และศูนย์ข้อมูล (Cloud & Data Center Infrastructure):** เน้นเทคโนโลยีเครือข่ายเสมือนจริง (Virtualization), การเชื่อมต่อระบบคลาวด์ (Cloud Networking), และการดูแลระบบเซิร์ฟเวอร์
- **สายโทรคมนาคมและเครือข่ายไร้สาย (Telecommunication & Wireless Networks):** เน้นเทคโนโลยี 4G/5G, คลื่นวิทยุ, เส้นใยแก้วนำแสง (Fiber Optic), และระบบ IoT (Internet of Things)

## 2. วิชาแกนหลักที่ต้องเจอ (Core Subjects)
การเรียนจะเน้นทั้งทฤษฎีการสื่อสารข้อมูลและการลงมือปฏิบัติจริงในห้องแล็บที่จำลองอุปกรณ์เครือข่ายของจริง ตัวอย่างวิชาเรียนและโปรเจกต์ที่สำคัญ ได้แก่:

### รายวิชาเด่น
- Data Communication and Computer Networks: พื้นฐานการสื่อสารข้อมูล, แบบจำลอง OSI Model, และโปรโตคอล TCP/IP
- Routing and Switching: การกำหนดเส้นทางข้อมูลและการสลับสายสัญญาณ (ในไทยมักอ้างอิงเนื้อหาและการตั้งค่าตามมาตรฐานของอุปกรณ์ Cisco)
- Network Administration and Management: การดูแลระบบปฏิบัติการเครือข่าย (Linux/Windows Server), การตั้งค่า DNS, DHCP และ Active Directory
- Wireless and Mobile Networks: เทคโนโลยีเครือข่ายไร้สาย, Wi-Fi, เซนเซอร์เครือข่าย (Sensor Networks)
- Network Security: การรักษาความปลอดภัยเครือข่าย, การเข้ารหัสข้อมูล, และการตั้งค่าระบบป้องกันการบุกรุก (Firewall / IDS / IPS)

### โปรเจกต์ที่มักจะได้ทำระหว่างเรียน
- Enterprise Network Design: การออกแบบระบบเครือข่ายสำหรับอาคารหรือองค์กรขนาดใหญ่ พร้อมประเมินราคาอุปกรณ์ ทราฟฟิก และการเดินสาย
- Server and Infrastructure Setup: การจำลองการติดตั้งและปรับแต่งเว็บเซิร์ฟเวอร์, อีเมลเซิร์ฟเวอร์, หรือระบบฐานข้อมูลบนเครือข่าย
- Network Troubleshooting & Simulation: การใช้โปรแกรมจำลอง (เช่น Cisco Packet Tracer, GNS3, EVE-NG) เพื่อแก้ปัญหาเครือข่ายล่มหรือหาคอขวด (Bottleneck) ของระบบ

## 3. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง?

### อาชีพสายตรง (จบปุ๊บ ทำตำแหน่งอะไรได้บ้าง?)
- Network Engineer: วิศวกรเครือข่าย ผู้ออกแบบ ติดตั้ง และบำรุงรักษาระบบเครือข่ายขององค์กร
- Network Administrator / System Administrator: ผู้ดูแลระบบเครือข่ายและเซิร์ฟเวอร์ คอยจัดการสิทธิ์ผู้ใช้งานและแก้ปัญหาการใช้งานรายวัน
- NOC Engineer (Network Operations Center Engineer): วิศวกรประจำศูนย์ปฏิบัติการเครือข่าย ทำหน้าที่เฝ้าระวัง (Monitor) และแก้ไขปัญหาระบบเครือข่ายตลอด 24 ชั่วโมง (มักทำงานเป็นกะให้กับผู้ให้บริการอินเทอร์เน็ต หรือ ISP)
- Telecommunications Engineer: วิศวกรโทรคมนาคม (ดูแลระบบเสาสัญญาณ หรือโครงข่ายผู้ให้บริการมือถือ/อินเทอร์เน็ต)
- Pre-Sales / Post-Sales Engineer (Network): วิศวกรสนับสนุนงานขาย ที่ช่วยออกแบบโซลูชันเครือข่ายไปนำเสนอและติดตั้งให้ลูกค้าองค์กร

### อาชีพประยุกต์หรือข้ามสาย
- Cloud Engineer: วิศวกรคลาวด์ ผู้ดูแลโครงสร้างพื้นฐานบนผู้ให้บริการอย่าง AWS, Azure หรือ Google Cloud (งานสายนี้ต้องการพื้นฐาน Network ที่แม่นยำสูงมาก)
- DevOps Engineer: ผู้เชื่อมรอยต่อระหว่างการเขียนโค้ดและการดูแลระบบ (ต้องการทักษะ Network และ System ประกอบกัน)
- Cybersecurity / Network Security Engineer: วิศวกรความปลอดภัยเครือข่าย (ต่อยอดจากการดูเรื่อง Firewall สู่การทำ Security เต็มรูปแบบ)

## 4. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน
วิศวกรรมเครือข่ายเป็นสายที่ให้ความสำคัญกับ **"ใบรับรองวิชาชีพ (Certifications)"** อย่างมากในการพิจารณารับเข้าทำงานและปรับฐานเงินเดือน:

### ใบรับรอง (Certifications) ที่แนะนำและตลาดแรงงานไทยต้องการสูง
- Cisco Certifications: เป็นมาตรฐานอุตสาหกรรมในไทย เริ่มต้นที่ **CCNA** (ถือเป็นใบเบิกทางที่นักศึกษาจบใหม่สายนี้ควรมี) และต่อยอดไปที่ระดับ **CCNP**
- CompTIA Network+: ใบรับรองพื้นฐานด้านเครือข่ายที่เป็นกลาง (Vendor-neutral)
- Cloud Networking Certifications: เช่น AWS Certified Advanced Networking - Specialty

### เทคโนโลยีที่ควรฝึกฝนเอง
- Network Automation / Programmability: ทักษะที่สำคัญมากในยุคปัจจุบัน คือการเขียนโค้ด (เช่น Python) หรือใช้เครื่องมือ (เช่น Ansible, Terraform) เพื่อตั้งค่าและจัดการอุปกรณ์เครือข่ายจำนวนมากแบบอัตโนมัติ (Software-Defined Networking - SDN)
- ระบบปฏิบัติการ Linux: ความคล่องแคล่วในการใช้ Command Line บน Linux (เช่น Ubuntu, CentOS) เป็นสิ่งจำเป็นอย่างยิ่งในการบริหารจัดการเซิร์ฟเวอร์และอุปกรณ์เครือข่ายรุ่นใหม่
- Virtualization & Containerization: ความเข้าใจในระบบจำลอง (VMware, Proxmox) และคอนเทนเนอร์ (Docker, Kubernetes) เนื่องจากระบบเครือข่ายและแอปพลิเคชันสมัยใหม่มักทำงานอยู่บนเทคโนโลยีเหล่านี้
