# สาขาวิชา: วิทยาการข้อมูล / วิทยาการวิเคราะห์ข้อมูล (Data Science / Data Analytics)

## 1. สาขานี้เรียนเกี่ยวกับอะไร? (Overview)
- ภาพรวมของสาขานี้: เน้นสถิติ คณิตศาสตร์ การใช้ Python/R เพื่อสกัดอินไซต์จากข้อมูล
- วิชาแกนหลักที่ต้องเจอ (Core Subjects): Probability & Statistics, Machine Learning, Data Mining, Data Visualization
- โปรเจกต์ที่มักจะได้ทำระหว่างเรียน: คลีนข้อมูลและวิเคราะห์พฤติกรรมลูกค้าจาก Dataset จริง, สร้างโมเดลทำนายยอดขายล่วงหน้า

## 2. จบสาขานี้ไปทำอาชีพอะไรได้บ้าง? (Career Paths)
- อาชีพสายตรง: Data Analyst, Data Scientist, BI Developer
- อาชีพประยุกต์หรือข้ามสาย: Machine Learning Engineer, Business Analyst, Prompt Engineer

## 3. ทักษะที่ควรศึกษาเพิ่มเติมนอกห้องเรียน (Additional Skills)
- ใบรับรอง (Certifications) ที่ควรสอบ: Google Data Analytics Professional Certificate, IBM Data Science Professional
- เทคโนโลยีที่ควรฝึกฝนเอง: นำ Dataset จากโลกจริงมาวิเคราะห์และแข่งขันจัดอันดับบนแพลตฟอร์ม Kaggle
